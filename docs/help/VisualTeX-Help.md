# VisualTeX 网页编辑器帮助手册

VisualTeX 网页编辑器采用与 Windows 主应用相同的公式编辑内核。网页端不会调用本地 OCR、快捷 OCR、小键盘窗口、Office 集成或桌面应用生命周期接口。

## 开始编辑

- 点击公式区域后直接输入 LaTeX，或使用公式磁贴插入结构。
- 可以增加多行公式，并为每一行选择行内公式或独立公式模式。
- 标题、主题、工具栏偏好与自定义公式会保存在当前浏览器中。
- 网页关闭后是否保留偏好取决于浏览器的隐私模式和站点数据设置。

## 输入与自动转换

- 常见名称和符号可以按输入规则自动转换为 LaTeX。
- 点击编辑区上方的“操作逻辑”可以开关转换规则并查看映射。
- 中文标点和常见全角字符会在适合的数学上下文中规范化。
- 输入法组合期间不会提前改写内容，提交后才执行兼容处理。

## 公式工具与自定义内容

- 标准布局在侧栏显示公式磁贴；经典布局把磁贴和源码区放在可调整的分栏中。
- 自定义公式磁贴、颜色和快捷键只写入当前浏览器站点存储。
- 自定义符号设计器支持浏览器内渲染。系统数学字体使用浏览器字体检测和 Canvas 渲染，不读取或上传本地字体文件。

## LaTeX 源码

- 展开源码区可直接修改整个公式文档。
- 有效源码会同步到可视化公式；不完整结构会保留草稿，避免破坏现有公式。
- 切换复制格式会同时影响源码区和复制结果。
- 混合行内/独立模式会按每行模式生成对应定界符。

## 文件与导出

- “保存”会下载 `.visualtex` 文档，不会写入任意本地目录。
- “打开”通过浏览器文件选择器读取用户明确选择的 `.visualtex` 或 JSON 文件。
- Markdown、SVG 和 PNG 导出由浏览器生成并下载。
- PNG 剪贴板写入需要 HTTPS、浏览器支持和用户授权；不支持时会显示错误，不会上传公式。

## 历史、撤销与恢复

- 可视化输入、源码编辑、标题修改和历史恢复都进入统一撤销栈。
- 历史恢复会保留每行的行内/独立模式。
- 浏览器会尽力在本地建立自动检查点；隐私模式或存储配额不足时，当前编辑仍可继续。
- 离开页面前请下载重要文档，浏览器清理站点数据会删除本地历史与偏好。

## 键盘快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 新建 | `Ctrl+N` | `Command+N` |
| 打开 | `Ctrl+O` | `Command+O` |
| 下载保存 | `Ctrl+S` | `Command+S` |
| 撤销 | `Ctrl+Z` | `Command+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` | `Command+Shift+Z` |
| 设置 | `Ctrl+,` | `Command+,` |
| 缩放 | `Ctrl++` / `Ctrl+-` / `Ctrl+0` | `Command++` / `Command+-` / `Command+0` |

这些快捷键会阻止浏览器的同名默认操作，只在没有打开设置、历史或帮助对话框时生效。

## 浏览器权限与隐私

- 公式编辑、渲染、文件解析和导出默认在浏览器本地完成。
- 网页编辑器不会保存或发送 OCR 服务密钥，也不会直接调用需要秘密密钥的第三方 API。
- 剪贴板只在用户点击复制或使用对应快捷键后访问。
- 打开的文件只在当前页面内解析；保存和导出通过浏览器下载机制完成。
- 如以后启用在线 OCR，应通过同源服务端代理和用户会话鉴权，不能把供应商密钥写进前端代码或浏览器存储。

## 网页端不提供的桌面功能

- 本地 OCR、截图 OCR、静默 OCR 与全局快捷 OCR。
- 独立小键盘窗口、复制后最小化或退出应用。
- Word、PowerPoint、MathType 和 OLE 集成。
- 原生文件系统目录写入、桌面自动更新和窗口控制。

这些入口已从网页编辑器中移除，避免浏览器误触原生命令或泄露本地信息。

## 故障排查

1. 编辑器空白时先刷新页面；若渲染崩溃，页面会显示错误详情和“重新加载”按钮。
2. 无法复制 PNG 时，确认网站使用 HTTPS，并允许剪贴板权限。
3. 偏好无法保存时，检查是否处于隐私模式、是否禁用了站点存储或存储空间已满。
4. 字体显示不同通常来自操作系统字体差异；网页端会使用可用字体自动降级。
5. 下载没有出现时，检查浏览器的自动下载拦截和默认下载目录。
