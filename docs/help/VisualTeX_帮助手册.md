# VisualTeX 帮助手册

**适用版本：网页版**

VisualTeX 用于可视化编辑 LaTeX 公式。Word、PowerPoint 插件、VisualTeX Anywhere 和本地 OCR 只在桌面版中提供。

第一次使用，可以先看主菜单里的 **新手教程**：每一课有真实编辑器的演示，并能直接动手练习。

---

# 1. 主界面


## 1.1 顶部栏

从左到右：

- **主菜单**：打开文件、导出、历史、OCR、设置、帮助等功能。
- **公式工具开关**：标准布局下为 **隐藏公式工具 / 显示公式工具**；经典布局下为 **收起公式磁贴 / 展开公式磁贴**。
- **文档标题**：直接点击标题修改；保存后旁边显示 **已保存**。
- **新建**：新建空白公式文档。
- **打开**：打开 `.visualtex` / `.visualtex.json` 文档。
- **保存**（保存到本地）：保存当前 VisualTeX 文档。
- **撤销**：撤销上一步编辑。
- **重做**：恢复已撤销编辑。
- **公式历史**：打开近期公式记录。
- **图片公式识别**：打开完整 OCR 窗口。
- **设置**：打开应用设置。
- **LaTeX 格式**：打开“通用 LaTeX 格式”配置（见第 9 章）。
- **导出**：打开 Markdown / SVG / PNG 导出。
- **操作逻辑**：设置自动转义和光标跳出。
- **缩小公式 / 放大公式**：调整可视化公式显示大小。

工具提示中写的 Ctrl 组合键在 macOS 上也可以用 ⌘。

## 1.2 编辑区底部栏

- **左对齐 / 居中 / 右对齐**：控制整行公式在编辑区中的位置。
- **粗体**：对选中内容切换 `\mathbf`。
- **斜体/正体**：在默认数学斜体与 `\mathrm` 正体之间切换。
- **字体颜色**：修改选中内容颜色。
- **背景颜色**：修改选中内容背景色。
- **持久化粗体输入**、**字形（自动数学字形 → 持久斜体 → 持久正体）**、**持久化字体颜色输入**、**持久化背景颜色输入**：开启后，之后输入的内容持续使用该格式。
- **LaTeX 源码（⌘\）**：展开或收起源码区。
- **复制 LaTeX 源码**：按当前 LaTeX 格式复制。


## 1.3 主菜单

菜单标题为 **VisualTeX · 公式工作区**。

- **新建公式**：新建空白文档。
- **打开文档**：打开 VisualTeX 文档。
- **保存文档**：保存 VisualTeX 文档。
- **导出…**：导出 Markdown、SVG、PNG。
- **公式历史**：打开历史记录。
- **图片公式识别**：打开完整 OCR 窗口。
- **设置**：打开设置。
- **帮助手册**：打开本手册。
- **检查更新**：检查 VisualTeX 新版本。
- **语言**：`CN` / `ENG` 切换界面语言。

# 2. 可视化公式编辑

## 2.1 基本输入

点击公式行后直接输入。

```latex
x^2+y^2=z^2
```

```latex
\frac{a+b}{c}
```

```latex
\sqrt{x+1}
```

- **Enter**：在普通公式中从当前光标位置拆分并新增公式行。
- **Shift+Enter**：在同一个公式内换行（多行对齐用这个）。
- **Ctrl+Enter** / **Option+Enter**：在光标处拆分，新行为行内 / 行间公式。
- **⌘⇧Enter**：当前公式行在行内与行间之间切换（多行公式固定为行间）。
- 以上三个快捷键可在“设置 → 公式快捷键 → 管理公式快捷键”的 **公式行** 中修改或关闭。
- 每行左侧的 `$` / `$$` 标记表示该行是行内还是行间公式，点击即可切换。
- **Tab**：移动到下一个可填写位置；候选框打开时可确认候选。
- **方向键**：移动光标或切换候选。
- **Esc**：关闭当前候选或临时输入状态。
- **粘贴图片**：在公式框中粘贴图片，直接进行 OCR。

## 2.2 命令候选

输入 `\` 开头的 LaTeX 命令时显示候选。

```latex
\frac
\sqrt
\int
\alpha
\begin{cases}
```

- 候选每页 9 个，当前页的候选标有 1–9 序号。
- **1–9**：直接选择当前页对应序号的候选。
- **↑ / ↓**：切换候选。
- **Enter / Tab**：确认当前候选。
- **Space**：确认当前候选。
- **Esc**：关闭当前候选。

启用个性化排序后，高频命令会优先显示。

## 2.3 `align` 自主对齐

`align` 不自动寻找等号。**对齐点由用户输入 `&` 指定。**

操作：

1. 在 **LaTeX 格式** 中把 **多行** 设为 `align`。
2. 在第一行需要对齐的位置（通常是 `=` 前）输入 `&`。
3. 按 **Shift+Enter** 在同一个公式内换行。
4. 在下一行对应位置再次输入 `&`。

示例：

```latex
a &= b+c \\
longvariable &= d-e
```

- `&` 只作为对齐标记，不显示为普通字符。
- 每一行可独立决定 `&` 的位置。
- 不输入 `&` 时，该行没有自主对齐点。
- **多行** 为 `gather` 时，输出不保留 `&`，各行居中。
- `&` 只在公式顶层作为 VisualTeX 多行对齐标记处理；进入 `cases`、矩阵等内部结构后按结构自身规则输入。
- **编号** 开启时输出 `align`，关闭时输出 `align*`。
- **Enter** 新建的是独立公式行，每行单独输出，不会与上一行对齐。

## 2.4 分段函数 `cases`

插入：

- **公式工具 → 结构 → 分段函数**。
- 或输入 `\begin{cases}` 并确认候选。

```latex
f(x)=\begin{cases}
x^2 & x>0\\
0 & x=0\\
-x & x<0
\end{cases}
```

**Enter 规则**：

- 光标仍在 `cases` 内：新增一个分段行。
- 光标退出 `cases` 后：新增 VisualTeX 公式行。

`cases` 内的 `&` 用于表达式列与条件列，不使用外层 `align` 的顶层对齐逻辑。

## 2.5 选中内容格式

先选中公式内容，再使用底部栏的格式按钮。

- **粗体**：切换 `\mathbf`。
- **斜体/正体**：切换默认数学斜体与 `\mathrm`。
- **字体颜色**：只修改选中内容。
- **背景颜色**：只修改选中内容；可选 **无背景**。
- **添加自定义颜色**：在颜色面板中保存颜色。
- **删除自定义颜色**：在自定义颜色列表中删除。

未选中内容时，这些按钮不是整篇公式的全局样式。需要让之后输入的内容一直带某种格式时，使用底部栏的持久化按钮。

## 2.6 公式缩放

- **缩小公式 / 放大公式**：以 5% 为步长调整，范围 20%–160%。
- `⌘0`：恢复 100%。
- `⌘+`：放大。
- `⌘-`：缩小。

缩放只影响编辑显示，不修改 LaTeX 源码。

## 2.7 复制 PNG

在可视化公式编辑区右键，选择 **复制 PNG 到剪贴板**。

PNG 使用当前：

- 数学字母字体
- 中文字体
- PNG 背景设置

# 3. 公式工具

## 3.1 工具分类

- **常用**：高频公式工具入口。
- **结构**：分数、根式、上下标、分段函数等。
- **微积分**：积分、求和、极限、导数等。
- **矩阵**：矩阵、向量、行列式、矩阵运算等。
- **关系**：等号、不等号、近似关系等。
- **希腊字母**：常用希腊字母。
- **箭头**：各类箭头。
- **物理常用**：常用物理符号与结构。
- **集合与逻辑**：集合、逻辑符号。

点击工具后，内容插入当前公式光标位置。

## 3.2 设置“常用”

操作：

1. 打开任意公式工具分类。
2. **右键**目标工具。
3. 点击 **设为常用**。
4. 工具移动到 **常用**靠前位置。

- 当前常用列表最多保留 45 项。
- “设为常用”只调整工具入口，不修改公式源码。

## 3.3 工具右键菜单

右键公式工具可使用：

- **设为常用**：将非当前常用工具提到常用列表前部。
- **设置快捷键**：绑定新的公式快捷键。
- **修改快捷键**：修改已有绑定。
- **清除快捷键**：删除该工具的绑定。

进入 **公式工具 → 矩阵 → 自定义矩阵**。

## 4.1 矩阵边界

- **无边界**：`matrix`
- **圆括号**：`pmatrix`
- **方括号**：`bmatrix`
- **花括号**：`Bmatrix`
- **单竖线**：`vmatrix`

## 4.2 矩阵尺寸

在尺寸网格中选择行数和列数，预览会同步变化。

确认后插入当前矩阵。

使用 **Tab** 在单元格之间移动。

## 4.3 矩阵快捷键

自定义矩阵也可绑定快捷键：

**选择尺寸和边界 → 右键当前矩阵 → 设置组合键**。

绑定后可直接插入同一尺寸、同一边界的矩阵。

# 5. 快捷键

入口：**设置 → 公式快捷键 → 管理公式快捷键**，打开“公式快捷键”窗口。窗口顶部显示已设置的数量。

窗口分为以下几节（自上而下）：

- **常用按钮**：为常用按钮设置快捷键（5.5）。
- **公式行**：新建行内 / 行间公式行和切换当前行（5.6）。
- **输入**：确认转义键（8.1）。
- **公式编辑器**：公式工具、磁贴、自定义矩阵的快捷键（5.1–5.4）。

## 5.1 新建公式快捷键

可绑定：

- 公式工具
- 常用公式磁贴
- 自定义公式磁贴
- 自定义矩阵

公式快捷键只在**可视化公式编辑区**生效。

1. 右键目标工具或磁贴。
2. 点击 **设置快捷键…**。
3. 按下组合键。
4. 点击 **绑定快捷键**。

组合键必须包含至少一个 `Control`、`Option` 或 `Command`；`Shift` 只能作为附加修饰键。

## 5.2 修改或删除

在“公式快捷键”窗口的 **公式编辑器** 一节中，每个绑定可：

- **修改快捷键**：重新录入组合键。
- **删除快捷键**：移除绑定。

也可直接右键原工具或磁贴进行修改、清除。

## 5.3 冲突与保留

- 系统保留快捷键不能覆盖。
- 与另一条公式快捷键重复时，界面显示冲突目标；点击 **替换并绑定** 后，新绑定替换旧绑定。
- 常用按钮快捷键优先：设为常用按钮的组合键会从公式快捷键或公式行快捷键中移过来。

受保护的快捷键包括：复制、剪切、粘贴、撤销、重做（`⇧⌘Z`、`⌘Y`）、新建、打开、保存、全选 `⌘A`、希腊字母输入 `⌘G`、设置 `⌘,`、缩放、公式 / 源码切换 `⌘\`，以及 `⌘H`、`⌘Q`、`⌘W`。

## 5.4 默认公式快捷键

| 功能 | 默认快捷键 |
|---|---|
| 平方根 | `⌘R` |
| 分式 | `⌘F` |
| 添加上下标 | `⌘J` |
| 下标 | `⌘L` |
| 角度 | `⌘D` |
| 偏微分符号 | `⇧⌘P` |

| 下划线 X | `⌥⇧X` |
| 下划线 Y | `⌥⇧Y` |

默认快捷键也会出现在 **公式编辑器** 一节中，可修改或删除。

## 5.5 常用按钮快捷键

**常用按钮** 一节中的动作初始均为 **未设置**。点击 **+** 后按下组合键（Esc 取消）。

- 打开 OCR 识别窗口、复制 LaTeX、复制为图片、显示 / 隐藏源码、导出、历史记录、显示 / 隐藏公式面板、设置、帮助。

组合键必须包含 Command、Option 或 Control，Shift 只能作为附加键。

## 5.6 公式行快捷键

| 功能 | 默认快捷键 |
|---|---|
| 新建行内公式行 | `Ctrl+Enter` |
| 新建行间公式行 | `Option+Enter` |
| 切换当前行的行内 / 行间 | `⌘⇧Enter` |

每项可 **修改快捷键**、**恢复默认** 或 **关闭快捷键**（关闭后显示“已关闭”）。

# 6. `⌘G` 希腊字母输入

在可视化公式编辑区：

1. 按 `⌘G`。
2. 松开后按对应字母。
3. 输入对应希腊字母。

按 `Esc` 可取消本次希腊字母输入。

## 6.1 小写

| 按键 | 输出 | 按键 | 输出 |
|---|---|---|---|
| A | `\alpha` | N | `\nu` |
| B | `\beta` | X | `\xi` |
| G | `\gamma` | O | `o` |
| D | `\delta` | P | `\pi` |
| E | `\epsilon` | R | `\rho` |
| Z | `\zeta` | S | `\sigma` |
| H | `\eta` | T | `\tau` |
| Q | `\theta` | U | `\upsilon` |
| I | `\iota` | F | `\phi` |
| K | `\kappa` | C | `\chi` |
| L | `\lambda` | Y | `\psi` |
| M | `\mu` | W | `\omega` |

小写 omicron 与拉丁字母 `o` 同形，因此输出 `o`。

## 6.2 大写

`⌘G` 后按 **Shift + 对应字母**。

例如：

- `⌘G` → `Shift+G`：`\Gamma`
- `⌘G` → `Shift+D`：`\Delta`

# 8. 操作逻辑

入口：顶部栏 **操作逻辑**。

## 8.1 输入自动转义

开启后，字母词只在按**确认转义键**时转换，而且只转换光标前的那个命令名，例如：

```text
alpha + 空格 → α
thetaalpha + 空格 → theta α（theta 不变；想转 theta 就在输入 theta 后先按一次空格）
frac + 空格 → 分式（光标进入分子）
>= → ≥（符号组合键入即转换）
```

`sin` 等函数名不转义，由自动正体排版处理。Tab、运算符、方向键等其他按键都不会触发转义。转换后紧接着按 Backspace 可恢复为键入的字母，在上下标、分式等任何结构中都有效。

确认转义键默认是 Space，可在 **设置 → 公式快捷键 → 管理公式快捷键 → 输入 → 确认转义** 中通过“设置确认转义键”修改、恢复默认或关闭。确认转义键可以是单个按键；Backspace、Delete、Enter、Esc 不能使用，不带修饰键的字母和数字也不能使用。

每个开关旁的 **查看映射** 打开“自动转义映射”，可在 **搜索输入或 LaTeX** 中查找。

**自动正体排版**是单独的开关：按 SI/ISO 规则把单位（km/h）、函数名（sin、lg(x)）、常数 e 和 i、微分 d、描述性下标（v_max）排成正体；关闭后完全不做正体判断。两个开关都不影响工具栏和候选框插入的内容。

两项默认：**开启**。

## 8.2 光标自动跳出

- **上标输入后跳出**：输入一个字符或工具栏符号后返回主公式区域。
- **下标输入后跳出**：同上。
- **重音内容输入后跳出**：适用于 `hat`、`bar`、`vec`、`tilde`、`dot` 等。
- **字体命令输入后跳出**：控制 `\mathbb{}`、`\mathbf{}`、`\mathcal{}` 等作用域。

关闭“字体命令输入后跳出”后，可连续输入多个字符，再按 **Enter** 确认字体作用域。

以上四项默认：**开启**。

# 9. LaTeX 格式

入口：顶部栏 **LaTeX 格式** 按钮，打开 **通用 LaTeX 格式**：一套持久化规则同时控制行内、行间与多行公式。

格式决定：

- 源码区域显示方式
- 复制 LaTeX 时的包装格式

不会改变公式的数学内容。每一行是行内还是行间，由该行左侧的 `$` / `$$` 标记决定（见 2.1）。

| 项目 | 选项 | 默认 |
|---|---|---|
| 文字 | `\text{}` / 公式外 | 公式外 |
| 行内 | `$...$` / `\(...\)` | `$...$` |
| 行间 | `$$...$$` / `\[...\]` / `equation` | `$$...$$` |
| 编号 | 开启 / 关闭 | 关闭 |
| 多行 | `gather` / `align` | `gather` |

- **文字**：行内公式中的中文等顶层文字，写成 `\text{...}` 放在公式内，或放到公式外。
- **行间**选 `equation` 时：编号开启输出 `equation`，关闭输出 `equation*`。
- **多行**：用 Shift+Enter 换行的公式输出为 `gather` 或 `align` 环境；编号关闭时为 `gather*` / `align*`。
- 多个公式行之间以空行分隔，各自按自己的行内 / 行间形式输出。

旧版本中的 `multline`、`split`、`aligned` 等格式已不再提供；旧配置会自动换算为上表中最接近的设置。

# 14. 自定义字符设计器

入口：**磁贴 → 自定义 → 字符设计器**。

用于组合 VisualTeX 内没有的数学字符，并注册为可直接输入的 LaTeX 命令。注册后可得到可在 LaTeX 文档中使用的 `\newcommand` 代码和 SVG。


## 14.1 界面

- **顶部**：标题、当前命令（未填写时显示“未命名草稿”；已注册字符显示“已注册”或“有未保存修改”）、**撤销（⌘Z）**、**重做（⌘⇧Z）**、**新建空白字符**、**已注册字符** 列表、关闭。
- **左侧**：素材（符号、字体字符、图形）。
- **中间**：画布工具栏、画布、代码面板。
- **右侧**：**属性**、**图层**、**注册** 三个标签页。

`Esc` 逐级退出：先关闭已注册字符列表，再离开文本框、回到选择工具、取消选择，最后关闭设计器。

## 14.2 基本流程

1. 从左侧加入符号、字体字符或图形。
2. 在画布上拖动、缩放、旋转，组合成新字符。
3. 在 **注册** 中选择基准字符和数学类型，填写命令。
4. 点击 **注册为命令**。
5. 在代码面板中复制 LaTeX 代码或 SVG。

## 14.3 素材

**符号**：

- 在输入框中输入 LaTeX（如 `\partial`），按 Enter 或点 **加入**。
- **搜索符号**：按命令、中英文名称和关键词查找。
- 分类：常用、微积分、希腊字母、关系、集合与逻辑、箭头、物理常用。
- “常用”中也列出已注册的自定义字符，可再次作为素材组合。
- 积分、求和等大型算子自动以显示样式（`\displaystyle`）加入。

**字体字符**：

- 字体：Cambria Math、STIX Two Math、Latin Modern Math、XITS Math、系统数学衬线回退；本机未安装的字体标有“未安装”。默认 Cambria Math。
- **正体 / 数学斜体**：默认数学斜体。
- 可按字符或 `U+` 编码搜索；分类有字母与数字、数学字母扩展、希腊字母、运算符、关系与逻辑、箭头、字母式符号、几何与技术符号。
- 字形通过 macOS Core Text 读取并转为矢量轮廓。

**图形**：线段、圆、椭圆、矩形、三角形、箭头、圆弧。

新加入的字符落在基线上，并与已有内容水平居中；图形以数学轴为中心。

## 14.4 画布与图层

画布工具栏：

- **选择与变换（V）**
- **平移画布（H，或按住空格）**
- **橡皮擦（E）**：可调 **粗细**。
- **参考字符**：x、α、∂、=、∫、Σ，可隐藏。

画布显示 **基线**、**数学轴**、**x 高度**、**大写高度** 参考线，以及字符的 TeX 盒子（宽 × 高 + 深，单位 em）。右下角可 **缩小**、**放大**、**适合字符**。

画布操作：

- 拖动图层移动；按住 Shift 只沿一个方向移动。
- 拖动四角等比缩放，按住 Shift 自由缩放；拖动四边中点只改变一个方向；对角点保持不动。
- 拖动上方旋转手柄旋转；按住 Shift 按 15° 吸附，不按 Shift 时接近 90° 的倍数会自动吸附。
- 滚轮平移，Shift+滚轮横向平移，⌘+滚轮或触控板捏合缩放。
- `⌘D` 复制图层；Delete 删除；方向键移动 0.01 em，Shift+方向键移动 0.1 em。

**图层** 标签页：最上层排在最前；每个图层可 **隐藏/显示**、**锁定/解锁**。锁定的图层仍可选中，但不能移动和缩放。

橡皮擦每一笔是一个独立的“橡皮擦轨迹”图层，擦除下方所有图形。

## 14.5 属性

- **图层名称**。
- **位置与大小**：水平位置、基线上升（em）、横向缩放、纵向缩放（%）、旋转（°）、倾斜（−60°～60°）；**锁定宽高比**（默认开启）、**水平翻转**、**垂直翻转**、**逆时针 90°**、**顺时针 90°**、**1:1**（恢复原始大小与角度）。
- 对齐：**落在基线上**、**与其他图层水平居中**、**以数学轴为中心**。
- 顺序与编辑：**上移一层**、**下移一层**、**复制图层**、**删除图层**。
- **图形**（仅图形图层）：宽度 / 长度、高度、线宽、圆角（矩形）、填充。
- **裁剪**（仅字符图层）：完整、上、中、下、左、中列、右；可用 **上中下三分**、**左中右三分** 把字符拆成三个图层。裁剪不删除原字形。
- **效果**：**空心描边**（描边粗细）、**立体挤出**（深度、方向、层数）。

## 14.6 基准字符、数学类型与上下限

在 **注册** 标签页中设置：

- **基准字符**：注册后的字符使用这个字符的 TeX 盒子，因此间距、上下标和上下限与它一致；其他图层可以超出盒子。默认 **自动（最大的正体素材）**；也可指定某个素材，或选 **无（按墨迹加边距）**。系统字体字符和旋转过的图层不能作为基准字符。
- 下方显示盒子尺寸，例如“按 \iint 的 TeX 盒子 · W × A + D em”；有斜体校正时一并显示。
- **斜体校正**：由基准字符自动测得，不能手动修改，只在数学类型为 **大型算子** 时使用。
- **数学类型**：普通字符 `\mathord`（默认）、二元运算符 `\mathbin`、关系符号 `\mathrel`、大型算子 `\mathop`、左定界符 `\mathopen`、右定界符 `\mathclose`、标点 `\mathpunct`。
- **上下限**（仅大型算子）：**自动**（默认，行间公式在上下方，行内在右侧）、**上下方 \limits**、**右侧 \nolimits**。

## 14.7 注册

- **命令**：只能由英文字母组成（a–z、A–Z），最多 48 个字母；不能与其他自定义字符、VisualTeX 或 LaTeX 已有命令重名。
- **名称（可选）**：留空时使用命令名。
- **Word 替代（可选）**：转换为 Word OMML 时用来代替该字符的 LaTeX，例如 `\approx`；不能使用其他自定义字符。
- 按钮：新字符为 **注册为命令**；修改已注册字符后为 **更新字符**；未修改时显示 **已注册**。

注册后：

- 命令进入公式输入候选（搜索“自定义字符”也能找到）。
- 在 **磁贴 → 自定义** 的“已注册字符”中出现，点击即可插入。
- 公式复制、粘贴、历史记录和重新编辑均保留原始命令。
- 自定义字符库随 **设置 → 配置备份与迁移** 一起保存和导入；换设备时需要一并迁移，否则该设备只能看到未解析的命令源码。

## 14.8 管理已注册字符

点击设计器顶部 **已注册字符**：

- 点击字符：载入并编辑。
- **复制为新草稿**：命令名后自动加 `copy`，名称后加“副本”。
- **删除** → **确认删除**：删除后，已有公式中的该命令将无法显示。重新注册同名命令或导入配置备份可以恢复显示。

磁贴区的已注册字符也可删除（再次点击确认），同时删除该字符的快捷键。

## 14.9 LaTeX 代码与 SVG

代码面板有两个标签页：

- **LaTeX \newcommand**：可直接放进 LaTeX 文档的命令定义，使用 picture 环境和 graphicx，随字号缩放。
- **SVG**：独立的 SVG，每 em 1000 单位，基线与文字基线对齐。

点击 **复制** 复制当前标签页内容。

LaTeX 代码的第一行是字符名称和命令，第二行 `% Preamble:` 列出导言区需要的宏包（总有 `amsmath`，按需加 `graphicx`、`pict2e`、`trimclip`）。若字符使用 Times 数学字体设计，还会提示配合 `newtxmath` 使用。橡皮擦和空心描边无法写进 LaTeX 代码时，面板会显示“LaTeX 代码不含：…”。

大型算子的代码直接叠加在真实的 TeX 运算符上，上下限由 TeX 自行处理。例如在 `\iint` 上加一个点：

```latex
% 带点二重积分 — VisualTeX custom symbol \dotiint
% Preamble: \usepackage{amsmath,graphicx}
\newcommand{\dotiint}{\mathop{\mathchoice
    {...}{...}{...}{...}}%
  \mskip-\thinmuskip\iint\displaylimits}
```

（`{...}` 为四种字号下叠加的内容，实际代码会完整给出。）基准字符经过缩放、旋转、裁剪或加了效果时，代码改用 `\NewDocumentCommand` 和 picture 绘制整个字符，需要 2020 年 10 月以后的 LaTeX 内核。

在 LaTeX 文档中使用：

1. 按代码第二行在导言区加载宏包。
2. 把复制的整段代码粘贴到导言区。
3. 在正文中像普通命令一样使用；大型算子后可加 `\limits` 或 `\nolimits` 改变上下限位置。

```latex
\documentclass{article}
\usepackage{amsmath,graphicx}
% 粘贴设计器复制的代码
\newcommand{\dotiint}{...}
\begin{document}
行内：$\dotiint_D f\,dA$
\[
  \dotiint_D f\,dA \qquad \dotiint\nolimits_D f\,dA
\]
\end{document}
```

# 17. 容易混淆的功能

## 常用工具 vs 常用磁贴 vs 自定义磁贴

- **常用工具**：已有公式结构或命令的高频入口。
- **常用磁贴**：从公式库选择的完整公式。
- **自定义磁贴**：用户保存的完整公式行。

## 整行对齐 vs `align` 对齐

- **左 / 中 / 右对齐**：控制整行公式在编辑区的位置。
- **`align` 的 `&`**：控制多行公式内部共同对齐点。

## 保存 vs 复制 LaTeX vs 导出

- **保存**：生成可继续编辑的 VisualTeX 文档。
- **复制 LaTeX**：按当前 LaTeX 格式复制源码到剪贴板。
- **导出**：生成 Markdown、SVG、PNG 外部文件。
