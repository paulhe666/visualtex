STIX Two Math
=============

STIXTwoMath-Regular.ttf is STIX Two Math 2.13 b171, unmodified: the TrueType
build the STIX Fonts project publishes (https://github.com/stipub/stixfonts,
tag v2.13b171, fonts/static_ttf/STIXTwoMath-Regular.ttf).
SHA-256 49B22767985171BCE579307B21D98F4D35012FA39E316ACC4FFCAB8644DFB69B

Copyright 2001-2021 The STIX Fonts Project Authors. It is distributed under
the SIL Open Font License 1.1; see STIX-Two-Math-OFL.txt.

VisualTeX installs this TrueType build (not the CFF .otf) because Microsoft
Word's built-in PDF export embeds TrueType math fonts and rasterizes CFF ones.
