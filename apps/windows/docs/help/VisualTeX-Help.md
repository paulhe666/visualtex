# VisualTeX 使用手册

**适用版本：Windows 1.3.0**

---

## 1. 快速开始

1. 打开 VisualTeX。
2. 在可视化编辑区输入公式，或从公式工具中插入结构。
3. 在 **LaTeX 格式** 中选择复制格式。
4. 复制源码、导出，或在 Word / PowerPoint / WPS 中插入公式。
5. 在其他应用中按 `Ctrl+Alt+M`，可直接在光标处输入公式（VisualTeX Anywhere，见第 12 章）。


---

## 2. 主界面

### 2.1 文件

- **新建**：新建公式文档。`Ctrl+N`
- **打开**：打开 `.json` / `.visualtex` 文档。`Ctrl+O`
- **保存到本地**：保存当前文档。`Ctrl+S`
- **导出…**：导出 Markdown、SVG 或 PNG。
- **撤销**：撤销编辑。`Ctrl+Z`
- **重做**：恢复撤销。`Ctrl+Y` / `Ctrl+Shift+Z`

### 2.2 常用入口

- **文档标题**：点击标题修改当前公式文档名称。
- **公式历史**：查看并恢复近期公式。
- **图片公式识别**：打开公式图片识别。
- **设置**：打开设置。`Ctrl+,`
- **帮助手册**：在 VisualTeX 内打开完整使用手册。
- **检查更新**：检查新版本。
- **语言**：切换中文 / English。

以上入口也在主菜单（**公式工作区**）中。

### 2.3 编辑区控制

- **公式对齐方式**：左对齐 / 居中 / 右对齐，设置公式整体位置。
- **缩小公式 / 放大公式**：调整编辑区显示比例（最小 20%）。`Ctrl+-` / `Ctrl+=`
- **恢复 100%**：恢复默认缩放。`Ctrl+0`
- **公式工具**：展开或收起公式工具区。
- **LaTeX 源码（Ctrl+\）**：展开或收起源码区；`Ctrl+\` 在公式与源码之间切换焦点。
- **复制 LaTeX 源码**：按当前 LaTeX 格式复制。
- **展开公式磁贴 / 收起公式磁贴**：显示或隐藏磁贴区。
- **小键盘**：进入或退出小键盘模式。`Ctrl+Shift+K`
- **快捷 OCR** 与 **OCR 识别器**：见第 11 章。

## 3. 布局

### 3.1 标准布局

- 可视化编辑区为主区域。
- 公式工具、源码区和磁贴按需展开。
- 适合常规编辑。

### 3.2 经典布局

默认布局。

- 底部使用 **公式工具 / LaTeX 源码** 标签切换。
- 底部面板可收起。
- 拖动底部边界可调整高度。
- 双击底部边界恢复默认高度。
- 聚焦边界后：`↑ / ↓` 微调，`Home / End` 调至最小 / 最大。
- 磁贴侧栏可拖动调整宽度。
- 双击侧栏边界恢复默认宽度。
- 聚焦侧栏边界后：`← / →` 微调，`Home / End` 调至最小 / 最大。

### 3.3 小键盘模式

- 点击顶部 **小键盘** 或按 `Ctrl+Shift+K` 进入；再次点击或按键退出。
- 隐藏普通主菜单、侧栏等非输入控件。
- 保留可视化编辑区、公式工具和当前 LaTeX 格式。
- 普通模式与小键盘模式分别记忆窗口宽高，互不覆盖。
- 首次进入小键盘模式默认使用较小的 760×260 窗口。
- 小键盘窗口可继续缩小到主应用最小尺寸 640×240。
- 退出小键盘后自动恢复普通模式上次窗口尺寸。
- 两套窗口尺寸均跨重启保存。
- `Ctrl+S`：按当前 LaTeX 格式复制源码。
- 默认复制成功后自动最小化 VisualTeX。
- **设置 → 界面自定义 → 小键盘复制后最小化主应用**：关闭自动最小化。
- 退出后恢复普通界面。

## 4. 可视化公式编辑

### 4.1 基本输入

- 直接输入字母、数字和运算符。
- LaTeX 命令以 `\` 开始。
- 支持中文与数学内容混合输入。
- 点击公式内部直接定位光标。
- 结构占位框中直接输入内容。

### 4.2 多行公式

- `Enter`：在光标处拆分并新建一行。
- `Ctrl+Enter` / `Alt+Enter`：在光标处拆分，新行为行内 / 行间公式。
- `Ctrl+Shift+Enter`：当前公式行在行内与行间之间切换（多行公式固定为行间）。
- 以上三个快捷键可在 **设置 → 快捷键 → 公式行** 中修改或关闭。
- 每行左侧的 `$` / `$$` 标记表示该行是行内还是行间公式，点击即可切换。
- `Shift+Enter`：在同一个公式内换行（多行对齐用这个）。
- 空行中按 `Backspace`：删除该行。
- 行首按 `Backspace`：与上一行合并。
- 支持上下方向键跨行移动。
- 可显示行号。
- 可高亮当前公式行。

### 4.3 多行选择

- 鼠标拖动可跨多行选择公式内容。
- `Delete / Backspace`：删除跨行选区并连接剩余内容。
- 复制、粘贴可保留 VisualTeX 多行结构。

### 4.4 希腊字母键盘 `Ctrl+G`

- 在公式编辑区按 `Ctrl+G` 激活一次希腊字母输入。
- 随后按字母键插入对应小写希腊字母。
- `Shift + 字母`：输入对应大写形式。
- `Esc`：取消本次希腊字母输入。
- 每次 `Ctrl+G` 只处理随后一个字母。

常用映射：

| 键 | 小写 | `Shift` 大写 |
|---|---|---|
| `A` | `α` | `A` |
| `B` | `β` | `B` |
| `G` | `γ` | `Γ` |
| `D` | `δ` | `Δ` |
| `Q` | `θ` | `Θ` |
| `L` | `λ` | `Λ` |
| `M` | `μ` | `M` |
| `X` | `ξ` | `Ξ` |
| `P` | `π` | `Π` |
| `R` | `ρ` | `P` |
| `S` | `σ` | `Σ` |
| `F` | `φ` | `Φ` |
| `Y` | `ψ` | `Ψ` |
| `W` | `ω` | `Ω` |

其余映射：`E→ε`、`Z→ζ`、`H→η`、`I→ι`、`K→κ`、`N→ν`、`O→o`、`T→τ`、`U→υ`、`C→χ`。

示例：`Ctrl+G` → `A` 插入 `\alpha`。

### 4.5 `align` 自主对齐

在 **LaTeX 格式** 中把 **多行** 设为 `align` 后：

- 将光标放到需要对齐的位置前。
- 输入 `&`。
- `&` 在可视化编辑区中不显示。
- 用 `Shift+Enter` 换行的各行，相同标记位置自动对齐。
- **多行** 为 `gather` 时，输出不保留 `&`，各行居中。

```latex
\begin{align}
f(x) &= x^2+1 \\
f^{\prime}(x) &= 2x
\end{align}
```

### 4.6 分段函数 `cases`

- **公式工具 → 结构 → cases**：插入分段函数。
- 左列填写表达式，右列填写条件。
- `cases` 内按 `Enter`：新增一行。

```latex
f(x)=\begin{cases}
x^2 & x\ge 0 \\
-x & x<0
\end{cases}
```

### 4.7 矩阵

- **公式工具 → 矩阵**：打开矩阵工具。
- 选择定界符。
- 在 10×10 网格中选择行数和列数。
- 点击 **插入当前矩阵** 插入。
- 右键当前矩阵可绑定快捷键。

支持：`matrix`、`pmatrix`、`bmatrix`、`Bmatrix`、`vmatrix`、`Vmatrix`。

```latex
A=\begin{bmatrix}
1&2\\
3&4
\end{bmatrix}
```

### 4.8 分式、根式、上下标

- **分式**：填写分子与分母。
- **根式**：填写根号内容；可继续添加根指数。
- **上标**：插入指数位置。
- **下标**：插入下标位置。
- **上下标**：同时创建上下标。
- **占位框**：点击后输入；完成后继续移动光标。

```latex
x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}
```

### 4.9 括号与重音

- **括号**：圆括号、方括号、花括号、绝对值等。
- **自动补全成对符号**：自动补全成对括号。
- **hat / bar / vec / tilde / dot**：添加重音或向量标记。

### 4.10 求和、积分与极限

- **积分**：普通积分、定积分、多重积分、围道积分。
- **求和**：`\sum` 及上下限。
- **连乘**：`\prod` 及上下限。
- **极限**：`\lim` 及趋近条件。
- **偏导**：`\partial`。
- **导数**：插入导数结构。
- **Nabla**：`\nabla`。
- **无穷**：`\infty`。

### 4.11 选区格式

先选择公式内容，再使用 **公式格式** 按钮：

- **粗体**：切换粗体。
- **斜体/正体**：在数学斜体与 `\mathrm` 正体之间切换。
- **字体颜色**：设置选区颜色。
- **背景颜色**：设置选区背景；可选 **无背景**。
- 支持预设颜色与自定义颜色（**添加自定义颜色**、**删除**）。

持久化输入：**持久化粗体输入**、**持久正体**、**持久化字体颜色输入**、**持久化背景颜色输入**。开启后，之后输入的内容持续使用该格式。

### 4.12 右键菜单

- 公式编辑区右键：**复制 PNG 到剪贴板**。

## 5. 快捷输入

### 5.1 默认公式快捷键

仅在可视化公式编辑区优先生效。

| 快捷键 | 功能 |
|---|---|
| `Ctrl+R` | 根式 |
| `Ctrl+F` | 分式 |
| `Ctrl+J` | 上下标 |
| `Ctrl+L` | 下标 |
| `Ctrl+D` | 度数 |
| `Ctrl+Shift+P` | 偏微分符号 |
| `Ctrl+Shift+I` | 定积分模板 |
| `Ctrl+Shift+S` | 求和模板 |
| `Alt+Shift+X` | 下划线 X |
| `Alt+Shift+Y` | 下划线 Y |

### 5.2 自定义公式快捷键

可绑定：

- 公式工具。
- 常用公式磁贴。
- 自定义公式磁贴。
- 自定义矩阵。

设置方法：

1. 右键公式工具、磁贴或矩阵。
2. 点击 **设置快捷键…**。
3. 按下组合键。
4. 点击 **绑定快捷键**。

规则：

- 快捷键必须包含 `Ctrl` 或 `Alt`。
- 仅 `Shift + 字母` 不可作为公式快捷键。
- 已被其他公式占用时，可覆盖原绑定。
- 系统保留快捷键不可覆盖。

### 5.3 快捷键窗口

入口：**设置 → 快捷键**。窗口自上而下分为：

- **常用按钮**：为常用按钮设置快捷键（5.8）。
- **公式输入法**：VisualTeX Anywhere 的快捷键（12.6）。
- **Office 快捷键**：Word / PowerPoint 新建公式的快捷键（5.9）。
- **公式行**：新建行内 / 行间公式行与切换当前行；每项可 **修改快捷键**、**恢复默认** 或 **关闭快捷键**（关闭后显示“已关闭”）。
- **输入**：**确认转义** 键（5.5）。
- **编辑器公式快捷键**：查看、修改、删除公式工具、磁贴和矩阵的快捷键。

### 5.4 保留快捷键

以下快捷键不可被公式快捷键覆盖：

- `Ctrl+C`：复制。
- `Ctrl+X`：剪切。
- `Ctrl+V`：粘贴。
- `Ctrl+Z`：撤销。
- `Ctrl+Y` / `Ctrl+Shift+Z`：重做。
- `Ctrl+N`：新建。
- `Ctrl+O`：打开。
- `Ctrl+S`：保存 / 小键盘复制。
- `Ctrl+G`：希腊字母键盘。
- `Ctrl+,`：设置。
- `Ctrl+0`：恢复缩放。
- `Ctrl+= / Ctrl++`：放大。
- `Ctrl+-`：缩小。

### 5.5 常用数学快捷转义

**操作逻辑 → 常用数学快捷转义**：

- 控制 `alpha`、`frac`、`>=`、`hat` 等快捷转义。字母词只在按**确认转义键**时转换，而且只转换光标前的那个命令名：`thetaalpha` 加 Space → theta α（theta 不变），`frac` 加 Space → 分式，`sin` 等函数名不转义（由自动正体处理）。Tab、运算符、方向键等其他按键都不会触发转义；`>=`、`->` 等符号组合仍即时转换。转换后紧接着按 Backspace 恢复为键入的字母，在上下标、分式等任何结构中都有效。
- 确认转义键默认 `Space`，在 **设置 → 快捷键 → 输入 → 确认转义** 中通过“设置确认转义键”修改、恢复默认或关闭。
- **查看映射**：查看完整转换表。
- 映射表支持搜索和分类。
- **自动正体排版**是单独的开关：按 SI/ISO 规则把单位、函数名、常数 e 和 i、微分 d、描述性下标排成正体；关闭后完全不做正体判断。两个开关都不影响工具栏和候选框插入的内容。

### 5.6 光标自动跳出

可分别设置：

- 上标输入后跳出。
- 下标输入后跳出。
- 重音内容输入后跳出。
- 字体命令输入后跳出。

字体命令关闭自动跳出后，可连续输入；按 `Enter` 结束作用域。

### 5.7 命令候选

输入 `\` 开头的命令时显示候选：

- 候选每页 9 个，当前页标有 1–9 序号；按数字键直接选择。
- `↑ / ↓`：选择候选。
- `Enter`、`Tab` 或 `Space`：插入候选。
- 单击：选择。
- 双击：直接插入。

### 5.8 常用按钮快捷键

**常用按钮** 一节中的动作初始均为“无”；点击快捷键框后按下组合键即可（Esc 取消）。

- **主程序与编辑器窗口**：快捷截图识别（快捷 OCR）、打开 OCR 识别窗口、复制 LaTeX、复制为图片、显示 / 隐藏源码。
- **主程序**：导出、历史记录、显示 / 隐藏公式面板、开启 / 关闭静默 OCR、设置、帮助。
- **Office 编辑器窗口**：取消编辑（编辑器窗口）。

### 5.9 Office 快捷键

在 Word、PowerPoint、WPS 文字和 WPS 演示的正文中直接新建公式的快捷键，四个应用分别设置，默认均为“无”。

Word 和 WPS 文字：

| 动作 | 格式 |
|---|---|
| 插入行内公式 | OLE（默认）/ OMML |
| 插入行间公式 | OLE（默认）/ OMML |

PowerPoint 和 WPS 演示：新建 SVG 公式、新建 OLE 公式、插入行内 OMML 公式、插入行间 OMML 公式。

规则：

- 快捷键必须包含 `Ctrl` 或 `Alt`，`Shift` 可作为附加键；按键可用字母、数字或 F1–F24。Word 和 WPS 文字的快捷键必须包含 `Ctrl`（仅含 `Alt` 的组合键保留给菜单），功能键只支持 F1–F16。
- 同一个组合可以同时用于不同应用；同一应用内不能重复，录入已被另一个动作使用的组合时，它会移到当前动作。
- `Ctrl+Alt+O` 已保留给静默 OCR；VisualTeX Anywhere 的全局快捷键（默认 `Ctrl+Alt+M`、`Ctrl+Alt+Shift+M`）也不能使用，因为 Office 收不到它们；AltGr 不能设置为快捷键。
- 录入被拒绝时，原因显示在该行下方。
- **Word 自带和自定义快捷键优先。** 录入已被 Word 占用的组合时会提示占用它的 Word 功能，并给出可用的建议。Word 默认空闲的组合例如 `Ctrl+F7`、`Ctrl+Shift+Y`、`Ctrl+Alt+Q`、`Ctrl+Alt+Shift+I`、`Ctrl+Alt+Shift+D`。之后在 Word 中发生冲突时，设置中显示“在 Word 中不会生效：… 已被 … 占用。”，Word 状态栏也会提示已交给 Word 处理。
- **WPS 文字自带的快捷键优先。** 按下已被 WPS 使用的组合时，VisualTeX 交给 WPS 处理，并在 WPS 状态栏提示占用它的 WPS 功能。
- 修改后立即生效，不需要重启 Office 或 WPS。
- 设为“无”即可停用。

## 6. 公式工具与磁贴

### 6.1 工具分类

- **常用**：高频命令。
- **结构**：分式、根式、上下标、括号、分段函数等。
- **微积分**：积分、求和、极限、偏导、导数等。
- **矩阵**：矩阵、定界符及字体变体。
- **关系**：等于、不等、约等、大小关系等。
- **希腊字母**：希腊字母。
- **箭头**：箭头符号。
- **物理**：物理常用符号。
- **集合**：属于、包含、全称、存在等。

字体变体包括：数学粗体、黑板粗体、数学正体、大写数学花体、手写花体、数学哥特体、数学粗斜体等。

### 6.2 常用工具

- 右键普通公式工具：可 **设为常用**。
- 常用工具最多 45 个。
- 个性化排序开启后，可按使用情况调整顺序。

### 6.3 常用公式磁贴

- 点击磁贴：插入公式。
- 右键磁贴：设置快捷键、**从常用中移除**。
- **添加磁贴**（从公式库添加磁贴）：打开“添加常用磁贴”，按 **数学 / 物理 / 化学** 分类和 **中学 / 大学 / 研究** 程度浏览，或 **搜索公式**；点击公式即可添加或移除。

默认磁贴包括：求根公式、欧拉恒等式、勾股定理、二项式定理、高斯积分、泰勒展开、质能方程、薛定谔方程、高斯定律、矩阵特征方程。

### 6.4 自定义公式磁贴

- **保存当前公式**：将当前非空公式保存为磁贴。
- **新建分区**：创建磁贴分组。
- 自定义公式最多 30 个。
- 分区最多 12 个。
- 分区可重命名。
- 删除分区会同时删除其中磁贴。

右键自定义磁贴：

- 设置 / 修改 / 清除快捷键。
- **磁贴颜色**（自动颜色、预设色或自定义颜色）。
- **所属分区**：移动到其他分区。
- **删除磁贴**。

## 7. 自定义字符设计器

入口：**磁贴 → 自定义 → 字符设计器**。

用于组合 VisualTeX 内没有的数学字符，注册为可直接输入的 LaTeX 命令，并得到可在 LaTeX 文档中使用的 `\newcommand` 代码和 SVG。


### 7.1 界面

- **顶部**：标题、当前命令（未填写时显示“未命名草稿”；已注册字符显示“已注册”或“有未保存修改”）、**撤销（Ctrl+Z）**、**重做（Ctrl+Shift+Z）**、**新建空白字符**、**已注册字符** 列表、关闭。
- **左侧**：素材（符号、字体字符、图形）。
- **中间**：画布工具栏、画布、代码面板。
- **右侧**：**属性**、**图层**、**注册** 三个标签页。

`Esc` 逐级退出：先关闭已注册字符列表，再离开文本框、回到选择工具、取消选择，最后关闭设计器。

### 7.2 基本流程

1. 从左侧加入符号、字体字符或图形。
2. 在画布上拖动、缩放、旋转，组合成新字符。
3. 在 **注册** 中选择基准字符和数学类型，填写命令。
4. 点击 **注册为命令**。
5. 在代码面板中复制 LaTeX 代码或 SVG。

### 7.3 素材

**符号**：

- 在输入框中输入 LaTeX（如 `\partial`），按 Enter 或点 **加入**。
- **搜索符号**：按命令、中英文名称和关键词查找。
- 分类：常用、微积分、希腊字母、关系、集合与逻辑、箭头、物理常用。
- “常用”中也列出已注册的自定义字符，可再次作为素材组合。
- 积分、求和等大型算子自动以显示样式（`\displaystyle`）加入。

**字体字符**：

- 字体：Cambria Math、STIX Two Math、Latin Modern Math、XITS Math、系统数学衬线回退；本机未安装的字体标有“未安装”。默认 Cambria Math。
- **正体 / 数学斜体**：默认数学斜体。
- 可按字符或 `U+` 编码搜索；分类有字母与数字、数学字母扩展、希腊字母、运算符、关系与逻辑、箭头、字母式符号、几何与技术符号。
- 字形通过 Windows DirectWrite 读取并转为矢量轮廓。

**图形**：线段、圆、椭圆、矩形、三角形、箭头、圆弧。

新加入的字符落在基线上，并与已有内容水平居中；图形以数学轴为中心。

### 7.4 画布与图层

画布工具栏：

- **选择与变换（V）**
- **平移画布（H，或按住空格）**
- **橡皮擦（E）**：可调 **粗细**。
- **参考字符**：x、α、∂、=、∫、Σ，可隐藏。

画布显示 **基线**、**数学轴**、**x 高度**、**大写高度** 参考线，以及字符的 TeX 盒子（宽 × 高 + 深，单位 em）。可 **缩小**、**放大**、**适合字符**。

画布操作：

- 拖动图层移动；按住 Shift 只沿一个方向移动。
- 拖动四角等比缩放，按住 Shift 自由缩放；拖动四边中点只改变一个方向；对角点保持不动。
- 拖动上方旋转手柄旋转；按住 Shift 按 15° 吸附，不按 Shift 时接近 90° 的倍数会自动吸附。
- 滚轮平移，Shift+滚轮横向平移，Ctrl+滚轮或触控板捏合缩放。
- `Ctrl+D` 复制图层；Delete 删除；方向键移动 0.01 em，Shift+方向键移动 0.1 em。

**图层** 标签页：最上层排在最前；每个图层可 **隐藏/显示**、**锁定/解锁**。锁定的图层仍可选中，但不能移动和缩放。

橡皮擦每一笔是一个独立的“橡皮擦轨迹”图层，擦除下方所有图形。

### 7.5 属性

- **图层名称**。
- **位置与大小**：水平位置、基线上升（em）、横向缩放、纵向缩放（%）、旋转（°）、倾斜（−60°～60°）；**锁定宽高比**（默认开启）、**水平翻转**、**垂直翻转**、**逆时针 90°**、**顺时针 90°**、**1:1**（恢复原始大小与角度）。
- 对齐：**落在基线上**、**与其他图层水平居中**、**以数学轴为中心**。
- 顺序与编辑：**上移一层**、**下移一层**、**复制图层**、**删除图层**。
- **图形**（仅图形图层）：宽度 / 长度、高度、线宽、圆角（矩形）、填充。
- **裁剪**（仅字符图层）：完整、上、中、下、左、中列、右；可用 **上中下三分**、**左中右三分** 把字符拆成三个图层。裁剪不删除原字形。
- **效果**：**空心描边**（描边粗细）、**立体挤出**（深度、方向、层数）。

### 7.6 基准字符、数学类型与上下限

在 **注册** 标签页中设置：

- **基准字符**：注册后的字符使用这个字符的 TeX 盒子，因此间距、上下标和上下限与它一致；其他图层可以超出盒子。默认 **自动（最大的正体素材）**；也可指定某个素材，或选 **无（按墨迹加边距）**。系统字体字符和旋转过的图层不能作为基准字符。
- 下方显示盒子尺寸，例如“按 \iint 的 TeX 盒子 · W × A + D em”；有斜体校正时一并显示。
- **斜体校正**：由基准字符自动测得，不能手动修改，只在数学类型为 **大型算子** 时使用。
- **数学类型**：普通字符 `\mathord`（默认）、二元运算符 `\mathbin`、关系符号 `\mathrel`、大型算子 `\mathop`、左定界符 `\mathopen`、右定界符 `\mathclose`、标点 `\mathpunct`。
- **上下限**（仅大型算子）：**自动**（默认，行间公式在上下方，行内在右侧）、**上下方 \limits**、**右侧 \nolimits**。

### 7.7 注册

- **命令**：只能由英文字母组成（a–z、A–Z），最多 48 个字母；不能与其他自定义字符、VisualTeX 或 LaTeX 已有命令重名。
- **名称（可选）**：留空时使用命令名。
- **Word 替代（可选）**：转换为 Word OMML 时用来代替该字符的 LaTeX，例如 `\approx`；不能使用其他自定义字符。
- 按钮：新字符为 **注册为命令**；修改已注册字符后为 **更新字符**；未修改时显示 **已注册**。

注册后：

- 命令进入公式输入候选（搜索“自定义字符”也能找到）。
- 在 **磁贴 → 自定义** 的“已注册字符”中出现，点击即可插入。
- 公式复制、粘贴、历史记录和重新编辑均保留原始命令。
- 自定义字符库随 **设置 → 配置备份与迁移** 一起保存和导入；换设备时需要一并迁移，否则该设备只能看到未解析的命令源码。

### 7.8 管理已注册字符

点击设计器顶部 **已注册字符**：

- 点击字符：载入并编辑。
- **复制为新草稿**：命令名后自动加 `copy`，名称后加“副本”。
- **删除** → **确认删除**：删除后，已有公式中的该命令将无法显示。重新注册同名命令或导入配置备份可以恢复显示。

磁贴区的已注册字符也可删除（再次点击确认），同时删除该字符的快捷键。

### 7.9 LaTeX 代码与 SVG

代码面板有两个标签页：

- **LaTeX \newcommand**：可直接放进 LaTeX 文档的命令定义，使用 picture 环境和 graphicx，随字号缩放。
- **SVG**：独立的 SVG，每 em 1000 单位，基线与文字基线对齐。

点击 **复制** 复制当前标签页内容。

LaTeX 代码的第一行是字符名称和命令，第二行 `% Preamble:` 列出导言区需要的宏包（总有 `amsmath`，按需加 `graphicx`、`pict2e`、`trimclip`）。若字符使用 Times 数学字体设计，还会提示配合 `newtxmath` 使用。橡皮擦和空心描边无法写进 LaTeX 代码时，面板会显示“LaTeX 代码不含：…”。

大型算子的代码直接叠加在真实的 TeX 运算符上，上下限由 TeX 自行处理。例如在 `\iint` 上加一个点：

```latex
% 带点二重积分 — VisualTeX custom symbol \dotiint
% Preamble: \usepackage{amsmath,graphicx}
\newcommand{\dotiint}{\mathop{\mathchoice
    {...}{...}{...}{...}}%
  \mskip-\thinmuskip\iint\displaylimits}
```

（`{...}` 为四种字号下叠加的内容，实际代码会完整给出。）基准字符经过缩放、旋转、裁剪或加了效果时，代码改用 `\NewDocumentCommand` 和 picture 绘制整个字符，需要 2020 年 10 月以后的 LaTeX 内核。

在 LaTeX 文档中使用：

1. 按代码第二行在导言区加载宏包。
2. 把复制的整段代码粘贴到导言区。
3. 在正文中像普通命令一样使用；大型算子后可加 `\limits` 或 `\nolimits` 改变上下限位置。

```latex
\documentclass{article}
\usepackage{amsmath,graphicx}
% 粘贴设计器复制的代码
\newcommand{\dotiint}{...}
\begin{document}
行内：$\dotiint_D f\,dA$
\[
  \dotiint_D f\,dA \qquad \dotiint\nolimits_D f\,dA
\]
\end{document}
```

## 8. LaTeX 源码

### 8.1 源码编辑器

- 可视化编辑区与源码实时同步。
- 支持语法高亮。
- 支持行号和自动换行。
- 可直接修改源码。
- 源码不完整或无效时显示错误状态。
- 可恢复到有效源码。
- **复制 LaTeX 源码**：按当前 LaTeX 格式复制。
- **收起**：关闭源码区。
- 源码字体大小在 **设置 → 界面自定义 → LaTeX 源码 → 源码字体大小** 中调整（8–32，默认 12）。

### 8.2 通用 LaTeX 格式

点击 **LaTeX 格式** 按钮打开 **通用 LaTeX 格式**：一套持久化规则同时控制行内、行间与多行公式。它决定源码区显示、复制 LaTeX、小键盘 `Ctrl+S` 复制和 VisualTeX Anywhere 的 LaTeX 输出。每一行是行内还是行间，由该行左侧的 `$` / `$$` 标记决定。

| 项目 | 选项 | 默认 |
|---|---|---|
| 文字 | `\text{}` / 公式外 | 公式外 |
| 行内 | `$...$` / `\(...\)` | `$...$` |
| 行间 | `$$...$$` / `\[...\]` / `equation` | `$$...$$` |
| 编号 | 开启 / 关闭 | 关闭 |
| 多行 | `gather` / `align` | `gather` |

- **文字**：行内公式中的中文等顶层文字，写成 `\text{...}` 放在公式内，或放到公式外。
- **行间**选 `equation` 时：编号开启输出 `equation`，关闭输出 `equation*`。
- **多行**：用 Shift+Enter 换行的公式输出为 `gather` 或 `align` 环境；编号关闭时为 `gather*` / `align*`。
- 多个公式行之间以空行分隔，各自按自己的行内 / 行间形式输出。

旧版本中的 `multline`、`split`、`aligned` 等格式已不再提供；旧配置会自动换算为上表中最接近的设置。

## 11. OCR

### 11.1 公式图片 OCR

- **选择图片**：打开图片文件。
- 支持拖入图片。
- OCR 窗口打开时可直接粘贴剪贴板图片。
- **开始识别**：使用当前保存的 OCR 提供器执行识别。
- **取消识别**：停止当前本地 Worker 或远程 API 请求。
- **复制 LaTeX**：复制结果。
- **插入当前光标**：插入当前公式位置。
- **追加为新行**：新建公式行并插入。
- 同一套提供器配置会同时用于主 OCR 窗口、编辑区图片粘贴、快捷 OCR、静默 OCR、VisualTeX Anywhere，以及 Word/PowerPoint 中的 OCR。
- 编辑区工具栏的 **OCR 识别器** 下拉框（分组 **本地模型** / **OCR API**）可直接切换识别器。

### 11.2 OCR 提供器与 API

OCR 窗口顶部可选择并保存以下提供器；默认为完全本地的 **PP-FormulaNet**：

- **本地 PP-FormulaNet**：图片不离开本机，使用下方选择的 S / M / L 模型。
- **OpenAI 兼容 API**：**协议** 可选 **Responses API** 或 **Chat Completions**，可填写基础地址、视觉模型、API 密钥和识别提示词。VisualTeX 以 data URL 发送图片，优先请求 JSON Schema 结构化输出；兼容服务器不支持结构化输出时会自动回退一次。
- **Ollama**：调用基础地址下的 `/api/chat`，以 base64 图片、`stream=false` 和 JSON 输出结构请求本地视觉模型。
- **Mathpix**：调用 `POST /v3/text`，使用 `app_id` / `app_key` 请求头，优先读取 `latex_styled`，缺失时读取 `text`。Mathpix 对 base64 图片限制为 2 MB，超过时 VisualTeX 会在发送前提示裁剪或压缩；请求默认携带 `metadata.improve_mathpix=false`。
- **PaddleOCR 星河 API**
- **SimpleTex**

OpenAI 兼容接口和 Ollama 的标准返回目标为：

```json
{
  "formulas": [
    { "latex": "x^2+y^2" }
  ]
}
```

VisualTeX 也会兼容单个 `latex` 字段、公式字符串数组、Markdown JSON 代码块，以及仅返回一段 LaTeX 的接口，并统一转换为应用内部的 `formulas[].latex` 结果。

安全规则：

- API 密钥只保存在 Windows 原生后端，使用当前 Windows 用户的 DPAPI 加密；界面重新打开时只显示“已保存”，不会回显明文。
- 留空密钥输入框会继续使用已保存密钥；勾选删除后保存才会清除。
- 除 `localhost` / `127.0.0.1` 等本机回环地址外，携带密钥的接口必须使用 HTTPS；VisualTeX 会拒绝把密钥发送到远程明文 HTTP 地址。
- 使用远程提供器时，当前图片会发送到用户填写的接口；切回本地提供器后不会发送图片。
- 修改提供器、地址、模型或密钥后必须点击 **保存提供器**，未保存配置不会参与识别。

### 11.3 本地 OCR 模型

仅在选择 **本地 PP-FormulaNet** 时需要：

- **高速版 S**：较小模型。
- **均衡版 M（推荐）**：默认平衡模型。
- **高精度版 L**：较大模型。
- **下载**：下载并校验模型（按钮显示模型大小）；失败后可 **重试** 或 **续传**。
- **取消下载**：停止当前模型下载。
- **导入模型包**：离线导入 `.vtxocrmodel`；也可把模型文件拖到模型区域。
- **删除模型**：删除已安装模型。

### 11.4 本地 OCR 运行环境

仅在选择 **本地 PP-FormulaNet** 时需要：

- **安装 OCR 运行环境**：安装本地识别依赖。
- **取消安装**：停止当前运行环境安装。
- **重置环境**：重新建立 OCR 环境。
- **重启进程**：重启 OCR 后台进程。
- **查看日志**：打开 OCR 日志。
- 使用远程 API 提供器时不会启动或预热 PP-FormulaNet Worker。

### 11.5 OCR 存储位置

- 显示当前独立 OCR 存储路径。
- 显示所在磁盘可用空间。
- **更改位置**：选择新的 OCR 存储磁盘或目录。
- 已存在运行环境时，更改位置会重建 OCR 环境；模型需单独重新安装。
- **打开文件夹**：打开当前 OCR 存储目录。
- 可持久化的 OCR 数据在卸载后保留并自动复用。
- 可用空间不足 2 GB 时显示提示。

### 11.6 快捷 OCR

点击编辑区的 **快捷 OCR** 或按 `Ctrl+Shift+O`。快捷 OCR 菜单提供三种截图来源，默认使用 Windows：

- **Windows 截图工具（默认）**：直接打开 Windows 区域截图选择器。
- **PixPin**：VisualTeX 通过 PixPin 的脚本接口打开区域截图；完成后直接读取 PixPin 写入的新剪贴板图片。需要已安装或正在运行 PixPin。
- **其他截图工具 / 剪贴板**：VisualTeX 不启动截图程序，只等待下一张剪贴板图片；可配合 ShareX、Greenshot 或其他会把截图复制为图片的工具。
- 等待新图片最长 60 秒；旧剪贴板图片不会被误用。
- 截图提交后自动返回 VisualTeX，再使用当前保存的 OCR 提供器识别并插入原光标位置。

### 11.7 静默 OCR

- 用编辑区快捷 OCR 旁的图标开关开启 **静默 OCR**，开启后可在任意应用中使用；也可在“常用按钮”中为 **开启 / 关闭静默 OCR** 设置快捷键。
- 全局快捷键：`Ctrl+Alt+O`（固定）；该组合键已被其他程序占用时改用 `Ctrl+Alt+Shift+O`。
- 静默 OCR 与快捷 OCR 使用同一个截图来源设置：Windows、PixPin 或等待剪贴板。
- 框选截图后在后台使用当前保存的本地模型或远程 API 提供器识别。
- 识别时显示独立进度 HUD。
- 完成后按当前 LaTeX 格式复制结果。
- VisualTeX Anywhere 的公式打开期间，静默 OCR 快捷键暂停，`Ctrl+Alt+O` 用于切换公式输出格式。

### 11.8 编辑区图片粘贴 OCR

- 在公式编辑区粘贴图片可触发 OCR。
- 使用当前保存的本地模型或远程 API 提供器。
- 识别结果插回原光标位置。
- 本地 PP-FormulaNet 模式可对深色背景图片自动反色后识别；远程 API 获取原始图片并由接口自身处理。
- 识别期间显示进度并可取消。

## 12. VisualTeX Anywhere（公式输入法）

VisualTeX Anywhere 让你在任意应用的文本框中直接输入公式：按全局快捷键，公式出现在光标所在的行里，用 VisualTeX 编辑器输入，按 Enter 后公式以 LaTeX、Markdown、Unicode 或图片插入。它通过 VisualTeX 自带的输入法工作。

使用时 VisualTeX 需要保持运行。


### 12.1 安装

- 安装 VisualTeX 时，安装程序会为本机所有用户安装公式输入法（文本服务），此时会出现一次 Windows 用户账户控制（UAC）确认；已是当前版本时不再询问。
- 它不在任何语言的键盘列表里，输入法切换（`Win+空格`、`Ctrl+Shift`、`Shift`）不会切到它，也不影响你的中 / 英文输入法。只有 VisualTeX 的快捷键能打开公式。
- 拒绝 UAC 或安装失败时，VisualTeX 主程序照常可用，只是不能在其他应用中输入公式；重新运行安装包即可补装。
- 卸载 VisualTeX 时一并移除该输入法。


### 12.2 输入一个公式

1. 在任意应用中把光标放到要插入公式的位置。
2. 按 `Ctrl+Alt+M`（行内公式）或 `Ctrl+Alt+Shift+M`（行间公式）。
3. 公式出现在光标处，大小随文本框字号变化。直接输入，与主窗口的可视化编辑方式相同。公式打开期间，输入法列表里会临时出现“VisualTeX”，公式关闭后消失。
4. 按 **Enter** 插入；按 **Esc** 取消。

- 公式打开时，下方会短暂显示标签：输出格式、当前行是“行内”或“独立”（多行时显示第几行）、将要插入内容的预览，以及“切换输出格式”的快捷键。
- 再按一次 `Ctrl+Alt+M` / `Ctrl+Alt+Shift+M`，或焦点移到别处：公式收起，内容保留，下次按快捷键时继续编辑（用 `Ctrl+Alt+Shift+M` 继续时当前行改为行间）。
- **Esc**：放弃本次公式。有选区时，第一次 Esc 先取消选区。
- 公式中的 LaTeX 命令补全完成前、候选表打开时，Enter 先用于确认；在 `cases` 内 Enter 新增一行。
- 字体、自定义字符、LaTeX 格式等设置每次打开公式时从主窗口读取。
- 公式颜色按文本框背景自动取浅色或深色。
- 在浏览器、Electron 应用、Office 等文本框里，公式占据行内的位置，后面的文字随之后移。在使用旧式输入接口的程序里（微信、WPS、记事本等），输入时公式盖在光标后面的文字上，插入后文字正常排开。
- 公式关闭后（插入、取消或焦点移走），文本框回到打开公式前使用的输入法。

### 12.3 LaTeX 命令候选表

输入 `\` 开头的命令时，公式下方出现候选表：每列一个候选，上方是序号和命令，下方是按公式字号绘制的效果。

- 每页 9 个；**1–9** 直接选择。
- **↑ / ↓**：切换候选。
- **Enter**、**Tab** 或 **Space**：确认当前候选。
- 光标下方空间不足（例如靠近屏幕底部或任务栏）时，候选表显示在公式上方，公式仍留在原来的行里。


### 12.4 公式打开时的键盘

- 公式打开期间，按键直接交给公式：字母按英文输入（作为变量），中文输入法不会弹出候选。
- 公式里不能输入中文；需要中文时先插入公式，再在文本框里输入。
- 公式打开时切换输入法（例如 `Win+空格`），公式会收起，内容保留。

### 12.5 输出格式

Enter 时插入的内容由输出格式决定：

| 格式 | 插入内容 |
|---|---|
| LaTeX | 按主窗口 **LaTeX 格式** 输出，例如行内 `$...$`、行间 `$$...$$` |
| Markdown | 适合 Markdown 编辑器：行内 `$...$`（文字放在公式外），行间或多行用独立的 `$$...$$` 块 |
| Unicode | 用 Unicode 数学字符写成的纯文本，适合不支持公式的文本框；无法转换时插入 LaTeX |
| 图片 | PNG 图片，按文本框的背景色绘制，通过剪贴板粘贴到文本框 |

- 默认 LaTeX。每个应用分别记住上次使用的格式。
- `Ctrl+Alt+O`：切换到下一种输出格式（LaTeX → Markdown → Unicode → 图片）。
- 也可为每种格式单独设置快捷键（默认未设置）。

### 12.6 公式中的快捷键

| 功能 | 默认快捷键 |
|---|---|
| 进入 / 退出公式模式（全局） | `Ctrl+Alt+M` |
| 进入 / 退出独立公式（全局） | `Ctrl+Alt+Shift+M` |
| 切换到下一种输出格式 | `Ctrl+Alt+O` |
| 输出格式：LaTeX / Markdown / Unicode / 图片 | 未设置 |
| 当前行设为独立公式 | `Ctrl+Alt+D` |
| 当前行设为行内公式 | `Ctrl+Alt+I` |
| 切换行内 / 独立公式 | 未设置 |
| 截图识别公式（OCR） | `Ctrl+Alt+S` |
| 插入 / 取消 | `Enter` / `Esc` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 粘贴（图片自动识别） | `Ctrl+V` |
| 新建行内 / 行间公式行 | `Ctrl+Enter` / `Alt+Enter` |
| 切换当前行的行内 / 行间 | `Ctrl+Shift+Enter` |
| 同一公式内换行 | `Shift+Enter` |

- 多行公式固定为行间，设为行内时提示“多行公式保持独立公式”。
- 公式打开期间，Windows 键组合和 `Alt+Tab`、`Alt+F4`、`Alt+Space` 等系统快捷键照常由 Windows 处理；上表以外的 `Ctrl` 组合键仍由当前应用处理。

修改：**设置 → 快捷键 → 公式输入法**。点击铅笔后按下组合键（Esc 取消）；可恢复默认或设为未设置（“进入 / 退出公式模式”不能清除）。

- 组合键需要 `Ctrl` 或 `Alt`；Windows 键和 AltGr 不能使用。
- 公式中使用的快捷键必须包含 `Alt`（`Ctrl+Alt` 或 `Alt`），因为单独的 `Ctrl` 组合键归当前应用。
- 新建 / 切换公式行的快捷键与主窗口共用，在“公式行”中修改。

### 12.7 识别图片和截图

- **粘贴图片**：公式打开时按 `Ctrl+V`，剪贴板中的图片自动识别并插入光标处；剪贴板是文字时直接粘贴。
- **截图识别**：按 `Ctrl+Alt+S`，提示“请框选要识别的公式区域（Esc 取消）”，用 Windows 截图选择区域后，识别结果插入光标处，公式保持打开。
- 识别使用主窗口当前的 OCR 设置；使用本地模型时需要先安装 OCR 运行环境（见 11.4）。失败时显示“OCR 失败：…”。

### 12.8 输入法不可用时

- 没有安装公式输入法，或当前窗口没有接受它（约 1 秒内没有响应，例如 32 位程序、以管理员身份运行的程序，或不支持 Windows 文本服务的窗口）时，按 `Ctrl+Alt+M` 会在光标处打开一个独立的公式条，文本框的输入法保持不变。
- 公式条直接接收键盘输入，用法与上面相同；按 **Enter** 后公式条关闭，文本框重新获得焦点，公式通过剪贴板粘贴进去，随后剪贴板恢复为原来的内容。
- 点击其他位置时公式条收起，内容保留，下次按快捷键继续编辑；**Esc** 放弃。
- 按 Enter 时如果文本框已经关闭，公式复制到剪贴板，提示“已复制 · Ctrl+V 粘贴”。

## 15. Word 插件


### 15.1 新建公式

- **OLE 行内公式**：正文行内 VisualTeX OLE。
- **OLE 行间公式**：独立 VisualTeX OLE。
- **OMML 行内公式**：Word 原生行内公式。
- **OMML 行间公式**：Word 原生行间公式。
- 行间公式可选择是否编号。
- 也可用 Office 快捷键新建（见 5.9）。

### 15.2 编辑与转换

- **编辑所选公式**：编辑当前 VisualTeX 公式。
- **双击公式**：打开对应 VisualTeX 编辑窗口。

**公式格式转换**（“公式格式转换”组）：VisualTeX、MathType、OMML（Word 原生公式）之间互相转换。每一行是一个方向，行右侧有两个按钮：

- **所选**：只转换选区内的源格式公式。
- **全文**：转换整篇文档中的源格式公式，开始前会确认。
- 六个方向：VisualTeX → MathType、MathType → VisualTeX、OMML → MathType、MathType → OMML、VisualTeX → OMML、OMML → VisualTeX。
- 转换保留公式位置、行内/行间形式和编号。

### 15.3 公式编号

- **更新公式编号**：刷新 VisualTeX 编号，以及 MathType 原生编号和对应引用。
- **编号格式**：**全文连续编号（1）**、**按章编号（1.1）**、**按章编号（1-1）**、**按节编号（1.1.1）**、**按节编号（1.1-1）**。切换格式后立即应用于当前文档已有编号公式，并用于后续新插入的编号公式。
- **批量编号**：**为所选行间公式编号** / **为全文行间公式编号**。按当前编号格式，为未编号的行间公式（VisualTeX OLE、Word OMML、MathType）添加各自原生的编号；已有编号保持不变并自动顺延，交叉引用同步更新，可一次 `Ctrl+Z` 撤销。
- **更新公式格式**：把本文档中旧版 VisualTeX 写入的公式编号结构一次升级为当前格式；同时统一 OMML 公式字体：若 **OMML 字体** 选了具体字体，先把它设为文档数学字体，再让文档中每个 OMML 公式都使用文档数学字体（公式里单独写死的旧字体改为文档数学字体；`\mathrm`、`\text` 等普通文本保留原字体）；并用当前设置的字体（数学字体、中文字体、字母/希腊字母/数字字体）按公式保存的 LaTeX 重绘字体与之不同的 VisualTeX 公式，公式 ID、编号、引用、字号和行内/行间形式不变。开始前列出要改的项目，完成后报告更新的编号数、统一字体的公式数和重绘的公式数；公式内容、类型、编号和引用不变，重绘单独占一步撤销。没有字体记录的旧公式按未设字母/希腊字母/数字字体处理。VisualTeX 由 Office 启动、主窗口还没有打开过时不知道当前字体，此时不检查公式字体，并提示先打开主窗口。WPS 中不改 OMML 字体。

分栏的节（等宽或不等宽）中，行间公式在所在栏内居中，编号在该栏右端；表格中的公式以单元格为准。公式换到别的栏或分栏改变后，**更新公式格式**（以及有分栏的文档中的 **更新公式编号**）按公式现在所在的栏重设它的制表位，公式本身不变。

编号使用圆括号。VisualTeX OLE 行间公式的编号字体随公式字母字体：KaTeX 和 Times New Roman 公式的编号使用 Times New Roman；记录字母字体之前创建的旧公式保持正文字体。编号字体在新建、编辑、重绘或改字号时应用。

### 15.4 公式引用

- **插入公式引用**：分别从当前文档的 VisualTeX、Word OMML 或 MathType 带编号公式中选择目标，插入 Word `REF` 引用。
- 更新编号后引用同步更新。

### 15.5 批量导入

- **打开文件…** 导入 `.tex` / `.md` 文件，或直接粘贴源码。
- **源格式**：自动识别 / LaTeX / Markdown。
- **公式格式**：Word 原生 OMML（推荐）/ VisualTeX OLE / MathType OLE。
- **所有行间公式添加编号**。
- 左侧编辑源码，点击 **解析预览** 后右侧显示 Word 结构预览；修改源码后需重新解析。
- 显示正文、行内公式、行间公式等数量统计。
- 普通文本保持 Word 正文。
- 行内公式生成行内对象。
- 行间公式生成独立对象。
- **插入到 Word**：按当前预览结构提交。
- 导入后可继续逐个编辑。

### 15.6 LaTeX 重绘

**重绘所选**：

- LaTeX 重绘为 Word OMML。
- LaTeX 重绘为 VisualTeX OLE。
- LaTeX 重绘为 MathType。
- 所选 VisualTeX OLE 转为 LaTeX 代码。
- 所选 OMML 公式转为 LaTeX 代码。
- 所选 MathType 公式转为 LaTeX 代码。

**重绘全文**（开始前会确认）：

- 全文 LaTeX 重绘为 Word OMML。
- 全文 LaTeX 重绘为 VisualTeX OLE。
- 全文 LaTeX 重绘为 MathType。
- 全文 VisualTeX OLE 转为 LaTeX 代码。
- 全文 OMML 公式转为 LaTeX 代码。
- 全文 MathType 公式转为 LaTeX 代码。

重绘为公式时可以同时为行间公式添加编号；表格中的行间公式不编号（与批量编号相同），完成提示中会列出它们的数量。

### 15.7 公式字号

- **减小**：切换到较小字号。
- **字号**：选择中文字号（初号～八号）或磅值。
- **增大**：切换到较大字号。
- **OMML 字体**：Word 原生公式（OMML）的数学字体，按用户记住选择。
  - **跟随文档（不更改）**（默认）：不改文档的数学字体。
  - **Cambria Math**、**STIX Two Math（内置）**、**TeX Gyre Termes Math（内置）**、**Latin Modern Math（内置）**：选中后立即设为当前文档的数学字体并统一已有公式的字体（一次撤销）；之后 VisualTeX 每次写入 OMML（插入、编辑、转换、LaTeX 重绘、批量导入、编号改写）前都先把它设为该文档的数学字体。
  - STIX Two Math 和 TeX Gyre Termes Math 都是 Times 风格的数学字体，适合正文用 Times New Roman 的文档；TeX Gyre Termes Math 与 LaTeX 的 newtxmath 最接近。
  - 三种内置字体都由 Office 集成安装到 Windows 字体目录，都是 TrueType 版，另存为 PDF 时可嵌入。STIX Two Math 是 STIX 项目发布的原版；TeX Gyre Termes Math 和 Latin Modern Math 由 VisualTeX 转成 TrueType 并改名为 “VisualTeX TeX Gyre Termes Math”“VisualTeX Latin Modern Math”。内置字体若未加载，菜单项显示“内置字体未加载”，重新安装 Office 集成即可恢复。
  - 在没有安装这些字体的电脑上打开文档，Word 会改用 Cambria Math 显示公式。
  - Word 每个文档只有一种数学字体，改字体会改变该文档全部 OMML 公式。
  - WPS 文字没有文档数学字体：选中的字体只用于 VisualTeX 之后插入或编辑的 OMML 公式，已有公式在编辑后改用它；“跟随文档”时使用 Cambria Math。

### 15.8 兼容修复

- **修复公式偏移**：扫描全文中的 MathType / VisualTeX 行内 OLE，确认后只修复垂直偏移，不修改公式内容、字号、编号或引用。
- **修复公式显示**：扫描全文 MathType 公式，按公式原有数据重新生成显示图像，修复缺少 MathType 字体时生成的错误符号；公式数据、编号和引用保持不变。

### 15.9 OMML 编号布局

- VisualTeX 插入或转换得到的 Word 原生 OMML 仍是可由 Word 直接编辑的 `OMath`，不会改成 OLE 或图片。
- 带编号的行间 OMML 使用普通 Word 段落：`居中制表位 → OMath → 右对齐制表位 → (动态编号)`。公式位于页面可写区域中心，编号右边缘固定在页面可写区域右边界。
- 编号由隐藏 `SEQ`、可见 `REF` 和 VisualTeX 书签维护；按 `F9`、更新编号、编辑公式、格式转换或保存重开后仍保持动态引用。
- 旧版 VisualTeX 创建的三列表格 OMML 编号，会在第一次编辑、重绘或编号整理时迁移为制表位段落；包含普通用户正文的自定义表格不会被自动拍平。
- Office 集成会把 Latin Modern Math、TeX Gyre Termes Math 和 STIX Two Math 字体安装到 Windows 字体目录。

## 16. PowerPoint 插件

### 16.1 公式

- **新建 SVG / 新建 OLE / 新建 MathType**：在当前幻灯片新建对应形式的公式。
- **插入行内 OMML 公式**：在当前文本框的光标或文本选区处插入行内原生公式。
- **插入行间 OMML 公式**：正在编辑文本框时在光标处插入独立公式段落；否则在当前幻灯片创建独立原生公式。
- **编辑所选公式**：编辑当前公式。
- **双击公式**：打开对应 VisualTeX 编辑窗口。
- 删除公式：选中后按 Delete 键。
- 新建按钮可设置 Office 快捷键（见 5.9）。

### 16.2 转换

- 单个公式：双击打开编辑窗口，在“保存为”中选择 SVG、VisualTeX OLE、MathType OLE 或 OMML 后保存，即可改变它的形式。

**公式格式转换**（“公式格式转换”组）：MathType、OMML（PowerPoint 原生公式）、VisualTeX 之间批量互转。每一行是一个方向，行右侧有三个按钮：

- **所选**：转换所选对象中的公式；在左侧缩略图中选中幻灯片时，转换这些幻灯片上的全部公式。
- **本页**：转换当前幻灯片上的全部公式。
- **全部**：转换整个演示文稿中的公式，开始前会确认。
- **一键 统一**：把 **当前幻灯片** 或 **整个演示文稿** 中其他格式的公式全部转为同一种格式（MathType、OMML 或 VisualTeX）；已是该格式的公式不变。
- **VisualTeX 形式**：选择“→ VisualTeX”和“统一为 VisualTeX”生成的对象：**OLE 对象（双击编辑，嵌入文件）** 或 **SVG 图片（任何设备都能显示）**，两者都可双击编辑。
- **更新公式格式**：用当前设置的字体（数学字体、中文字体、字母/希腊字母/数字字体）按公式保存的 LaTeX 重绘字体与之不同的 VisualTeX 公式（SVG 图片和 OLE 对象）。每个公式保持形式、中心位置、显示大小、旋转和叠放次序，公式内容不变；开始前列出数量。撤销即可恢复（有 VisualTeX OLE 公式时撤销两次：第一次撤销 OLE 的尺寸校正）。

转换后保持不变的内容：

- 公式中心位置和显示字号。
- 显示颜色：包括深色主题中继承的白色文字；浅色主题下原生公式仍跟随主题颜色。
- 动画（含触发动画）、超链接、名称、替代文字、可见性、叠放次序、连接线。
- 旋转：目标为 OMML 或 SVG 图片时保留；翻转只有 SVG 图片能保留。
- 一个文本框里只有公式、但有多个公式时，每个公式各自成为一个对象。
- 占位符中的公式转为对象后，PowerPoint 自动补出的空占位符会被删除（标题占位符除外）。

以下公式不会转换，结束时会列出幻灯片和原因：

- 与普通文字在同一文本框中的 OMML 公式。
- 组合或表格中的公式。
- 目标格式无法保持的旋转或翻转（例如转为 MathType 或 OLE 对象）。
- 带动画、且一个文本框中有多个公式的 OMML 文本框。
- 链接的对象，以及无法读取源码的公式。
- 转换开始后被修改的公式。

转换过程：

- 进度窗口显示进度，可随时点 **停止**；已转换的公式保留。
- 转换期间 PowerPoint 窗口暂不接受输入，结束后自动恢复。
- 连续 3 个公式失败时自动停止并报告原因。
- PowerPoint 的撤销步数有限；大批量转换前请先保存文件。

### 16.3 LaTeX 重绘

“LaTeX 重绘”组把文本框中的 LaTeX 代码换成公式，或把公式换回 LaTeX 代码。

- **LaTeX → OMML**：把文本框中完整的 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 和 equation 等环境原位重绘为 PowerPoint 原生（OMML）公式，其余文字保持不变；`$$…$$` 和 `\[…\]` 成为单独居中的段落。列表项中间的行间公式后面的文字仍属于同一项。
- **LaTeX → VisualTeX** / **LaTeX → MathType**：只含一个 LaTeX 公式的文本框替换为 VisualTeX 公式（OLE 或 SVG，见“VisualTeX 形式”）或 MathType 公式，中心位置和字号不变。带填充或边框的形状和与文字混排的公式不替换，结束时会列出；这些公式请用 **LaTeX → OMML**。
- 每行有 **所选**、**本页**、**全部**：所选为选中的文本框（只选中部分文字时只处理其中完整的公式；在左侧缩略图中选中幻灯片时处理这些幻灯片）；本页为当前幻灯片；全部为整个演示文稿，开始前会确认。

**转为 LaTeX 代码**：文字中的原生公式原位替换为 `$…$`（单独成段的为 `$$…$$`），其余文字不变；VisualTeX 和 MathType 公式替换为中心位置、字号相同的文本框，内容为 `$$…$$`，之后可以用“LaTeX → …”重新绘制。菜单中可以转换各种格式的公式，也可以只转换 VisualTeX、MathType 或 OMML 公式。光标位于某个原生公式中（没有选中文字）时，只转换这个公式。

组合和表格中的文字不处理。转换期间 PowerPoint 窗口暂不接受输入；文本框在转换开始后被修改时，跳过这个文本框。

### 16.4 公式字号

- **减小**：切换到较小字号。
- **字号**：选择中文字号或磅值。
- **增大**：切换到较大字号。

## 17. WPS Office

Word 和 PowerPoint 的 VisualTeX 插件同样在 Windows 版 WPS 文字和 WPS 演示中运行，选项卡与 Office 中相同。

### 17.1 启用

- 安装 Office 集成时，安装程序会把两个插件登记到 WPS 的加载项白名单，不需要另外设置。
- 安装或更新后重新打开 WPS。

### 17.2 WPS 文字

- 插入和编辑 VisualTeX OLE、MathType 与 OMML 公式。
- 带编号的公式、编号格式切换和更新公式编号。
- **更新公式格式**：同样用当前字体重绘字体与设置不同的 VisualTeX 公式（见 15.3）。
- 公式引用在 WPS 中显示为普通文字，与 Word 一致。
- 文档可在 Word 与 WPS 之间往返编辑。

### 17.3 WPS 演示

- 插入和编辑原生公式（OMML）。
- 公式字号、选中公式、撤销和格式转换。
- **更新公式格式**：用当前字体重绘字体与设置不同的 VisualTeX 公式（见 16.2）。
- LaTeX 重绘和转为 LaTeX 代码（见 16.3）。WPS 中每个原生公式单独写入，公式较多时需要较长时间。
- 写入原生公式失败时提示“WPS 公式写入失败，文本框已被部分修改；请用撤销恢复并检查。”

VisualTeX OLE 公式在 WPS 中以平滑的矢量预览显示。

### 17.4 功能区图标

WPS 会把加载项自己的图标缩小并去掉透明背景，因此 VisualTeX 选项卡在 WPS 中使用 WPS 自带的同类图标，大小和配色与 WPS 一致；在 Word 和 PowerPoint 中仍是 VisualTeX 自己的图标。

### 17.5 MathType 与 WPS 启动报错

MathType 每次启动时都会把它的 VBA 模板“MathType Commands 2016.dotm”复制到 WPS 的启动文件夹。这个模板无法在 64 位 WPS 中运行，WPS 每次启动都会弹出“VBE6EXT.OLB 不能被加载”和“编译错误”等 VBA 提示。

- 检测到 64 位 WPS 和 MathType 时，VisualTeX 会在 WPS 启动文件夹中放一个同名、不含宏的占位模板，MathType 便不会再复制它的模板，WPS 启动时也不再报错。
- MathType 原来的模板移到 `%LOCALAPPDATA%\VisualTeX\office\mathtype-wps`。WPS 正在运行时模板被占用，VisualTeX 会在 WPS 关闭后完成替换。
- MathType 公式在 WPS 中仍由 VisualTeX 插件插入和编辑，不受影响。
- 删除占位模板后，MathType 会在下次启动时重新复制它的模板（VisualTeX 随后会再次替换）。

## 21. 常见操作

### 21.1 在等号处对齐多行公式

1. 在 **LaTeX 格式** 中把 **多行** 设为 `align`。
2. 在第一行 `=` 前输入 `&`。
3. 按 `Shift+Enter` 在同一个公式内换行，再在下一行 `=` 前输入 `&`。
4. 在源码区确认 `&=`。

注意：`Enter` 新建的是独立公式行，每行单独复制，不会与上一行对齐。

### 21.2 快速输入希腊字母

1. 在公式编辑区按 `Ctrl+G`。
2. 按对应字母键。
3. 大写使用 `Shift + 字母`。

### 21.3 为公式工具设置快捷键

1. 右键公式工具或磁贴。
2. 点击 **设置快捷键…**。
3. 输入组合键并保存。
4. 在 **设置 → 快捷键** 统一管理。

### 21.4 使用小键盘模式快速复制

1. 点击 **小键盘** 或按 `Ctrl+Shift+K`。
2. 选择所需 LaTeX 格式。
3. 编辑公式。
4. 按 `Ctrl+S` 复制。
5. 默认复制后自动最小化。

### 21.5 新增分段函数行

1. 插入 `cases`。
2. 将光标放在 `cases` 内。
3. 按 `Enter`。

### 21.6 在 Word 中使用原生公式

1. 选择 **OMML 行内公式** 或 **OMML 行间公式**。
2. 在 VisualTeX 中编辑。
3. 应用后可继续使用 Word 原生公式工具编辑。

### 21.7 在 Word 中使用可双击编辑对象

1. 选择 **OLE 行内公式** 或 **OLE 行间公式**。
2. 完成插入。
3. 后续双击公式重新打开 VisualTeX。

### 21.8 在聊天或网页中插入公式

1. 在目标文本框中放好光标。
2. 按 `Ctrl+Alt+M`，输入公式。
3. 需要时按 `Ctrl+Alt+O` 切换输出格式（例如 Markdown 或图片）。
4. 按 `Enter` 插入。

### 21.9 备份全部配置

1. 打开 **设置**。
2. 点击 **保存目前配置**。
3. 保存 `.vtxconfig`。
4. 在其他安装中使用 **导入配置**恢复。

## 22. 文档文件

文档模式的文档是普通的 Markdown 文件（`.md`）。

### 22.1 文档文件夹

- 默认位置：`文档\VisualTeX`（macOS：`文稿/VisualTeX`）。
- 文档库列出该文件夹中的 `.md`、`.markdown` 文件；文档库的文件夹就是它的子文件夹，文档名就是文件名。
- 文档库顶部的 **文档文件夹** 按钮可改用其他文件夹；原文件夹中的文件不动。
- 删除的文档移入该文件夹下隐藏的 `.trash`，30 天后清除；在 **最近删除** 中可恢复或立即删除。
- 文档的右键菜单：**重命名**、**创建副本**、**移到**、**导出**、**在资源管理器中显示**、**删除**。

### 22.2 新建、打开、保存

| 操作 | 说明 |
| --- | --- |
| **新建文档**（`Ctrl+N`） | 在文档文件夹中新建 `未命名文档.md` |
| **打开文档**（`Ctrl+O`） | 打开任意位置的 `.md`、`.markdown`、`.vtxdoc`，在原位置编辑；`.zip`（Markdown 导出包）和 `.json` 复制进文档文件夹（压缩包中的图片与文档文件夹中已有的图片重名时，文档和图片放入以文档命名的新文件夹） |
| **保存文档**（`Ctrl+S`） | 立即写入文件；编辑停顿后也会自动保存 |
| **另存为…**（`Ctrl+Shift+S`） | 另存为一个 Markdown 文件并转到该文件 |
| **导出 Markdown** / **导出 PDF** | 导出副本，当前文档不变 |

- 在文档文件夹之外打开的文件列在文档库的 **最近打开** 中；**从列表移除** 不删除文件，也不删除 VisualTeX 为它记住的格式（再次打开时恢复）。
- 在资源管理器中对 `.md` 文件选择 **打开方式 → VisualTeX**，或把文件拖到 VisualTeX 窗口，也会在原位置打开。VisualTeX 不会把自己设为 `.md` 的默认程序。

### 22.3 文件内容

- 文件中只有 Markdown：正文、`$…$` 行内公式、`$$` 行间公式、表格、`![说明](路径)` 图片、`[^1]` 脚注。
- 标题写成 `# 标题`；作者、日期、摘要、题注是普通文本行；带编号的公式写入 `\tag{n}`。
- 其他程序写的 Markdown 文件，未改动的行按原样保留（包括换行符、编码和 BOM）；改动一行只改写这一行。
- 图片是文件：其他程序写入的图片路径保持不变；新插入的图片存入文档旁的 `assets` 文件夹，使用原文件名，粘贴的图片命名为 `image-日期-时间.png`。

### 22.4 VisualTeX 记住的格式

Markdown 没有对应语法的内容不写入文件，由 VisualTeX 另行记住，再次用 VisualTeX 打开时恢复：

- 页面设置、字体、行距、公式编号格式、章节编号；
- 页面命令（`\newpage`、`\pagenumbering` 等）：在 VisualTeX 中插入的页面命令不写入文件，随其后一行记住；文件自己写有的这类命令行保持原样；
- 文字颜色、字号、底色，段落对齐和缩进；
- 哪一行是标题、作者、日期、摘要、题注；公式是否自动编号；图片宽度与环绕；表格的合并单元格、列宽和线型。

记录的位置：

- 文档文件夹中的文档：该文件夹下隐藏的 `.visualtex` 子文件夹。移动或同步整个文档文件夹时一并带走。
- 其他位置的文件：VisualTeX 的应用数据目录。文件在 VisualTeX 之外被移动或改名后，只要内容未变，仍能找回记录。

格式按行的文字对应。某一行被其他程序改写后，只有这一行的格式失效，其余保留。在 VisualTeX 中重命名、移动、创建副本、删除文档时，记录和图片随文档一起处理。

### 22.5 文件被其他程序修改

- 文件在磁盘上被修改，而 VisualTeX 中没有未保存的改动：回到 VisualTeX 窗口时自动重新载入。
- 两边都有改动：VisualTeX 询问 **重新载入**（放弃这里的改动）、**覆盖**（写入这里的版本）或 **另存副本**（这里的版本存为新文件，原文件保持磁盘上的内容）。

### 22.6 章节编号

新文档和打开的 Markdown 文件，章节标题默认不编号。在文档工具栏 **编号格式** 的 **章节编号** 中可选择 `1  1.1`、`1.  1.1.` 或 **无**。

### 22.7 旧版文档（`.vtxdoc`）

- 升级后首次进入文档模式时，旧文档库中的文档逐个转换为文档文件夹中的 `.md` 文件；每个文档转换后都会读回并与原文档比较。
- 无法精确转换的文档以 `.vtxdoc` 原样放入文档文件夹，并提示一次；`.vtxdoc` 仍可打开和编辑，用 **另存为…** 可存为 Markdown。
- 原文档库保留在应用数据目录中，不会删除。
