# VisualTeX 使用手册

**适用版本：Windows 1.2.6**

---

## 1. 快速开始

1. 打开 VisualTeX。
2. 在可视化编辑区输入公式，或从公式工具中插入结构。
3. 选择 **LaTeX 代码格式**。
4. 复制源码、导出，或在 Word / PowerPoint 中插入公式。

---

## 2. 主界面

### 2.1 文件

- **新建**：新建公式文档。`Ctrl+N`
- **打开**：打开 `.json` / `.visualtex` 文档。`Ctrl+O`
- **保存**：保存当前文档。`Ctrl+S`
- **导出**：导出 Markdown、SVG 或 PNG。
- **撤销**：撤销编辑。`Ctrl+Z`
- **重做**：恢复撤销。`Ctrl+Y` / `Ctrl+Shift+Z`

### 2.2 常用入口

- **文档标题**：点击标题修改当前公式文档名称。
- **公式历史**：查看并恢复近期公式。
- **公式图片 OCR**：打开公式图片识别。
- **设置**：打开设置。`Ctrl+,`
- **帮助手册**：在 VisualTeX 内打开完整使用手册。
- **检查更新**：检查新版本。
- **中文 / English**：切换界面语言。

### 2.3 编辑区控制

- **左对齐 / 居中 / 右对齐**：设置公式整体位置。
- **缩小 / 放大**：调整编辑区显示比例。`Ctrl+-` / `Ctrl+=`
- **恢复 100%**：恢复默认缩放。`Ctrl+0`
- **公式工具**：展开或收起公式工具区。
- **LaTeX 源码**：展开或收起源码区。
- **磁贴**：展开常用公式与自定义公式磁贴。
- **小键盘**：进入或退出小键盘模式。

---

## 3. 布局

### 3.1 标准布局

- 可视化编辑区为主区域。
- 公式工具、源码区和磁贴按需展开。
- 适合常规编辑。

### 3.2 经典布局

- 底部使用 **公式工具 / LaTeX 源码** 标签切换。
- 底部面板可收起。
- 拖动底部边界可调整高度。
- 双击底部边界恢复默认高度。
- 聚焦边界后：`↑ / ↓` 微调，`Home / End` 调至最小 / 最大。
- 磁贴侧栏可拖动调整宽度。
- 双击侧栏边界恢复默认宽度。
- 聚焦侧栏边界后：`← / →` 微调，`Home / End` 调至最小 / 最大。

### 3.3 小键盘模式

- 点击顶部 **小键盘** 进入；再次点击退出。
- 隐藏普通主菜单、侧栏、OCR、缩放等非输入控件。
- 保留可视化编辑区、公式工具和当前 LaTeX 代码格式。
- 普通模式与小键盘模式分别记忆窗口宽高，互不覆盖。
- 首次进入小键盘模式默认使用较小的 760×260 窗口。
- 小键盘窗口可继续缩小到主应用最小尺寸 640×240。
- 退出小键盘后自动恢复普通模式上次窗口尺寸。
- 两套窗口尺寸均跨重启保存。
- `Ctrl+S`：按当前 LaTeX 代码格式复制源码。
- 默认复制成功后自动最小化 VisualTeX。
- **设置 → 小键盘复制后最小化主应用**：关闭自动最小化。
- 退出后恢复普通界面。

## 4. 可视化公式编辑

### 4.1 基本输入

- 直接输入字母、数字和运算符。
- LaTeX 命令以 `\` 开始。
- 支持中文与数学内容混合输入。
- 点击公式内部直接定位光标。
- 结构占位框中直接输入内容。

### 4.2 多行公式

- `Enter`：在光标处拆分并新建一行。
- 空行中按 `Backspace`：删除该行。
- 行首按 `Backspace`：与上一行合并。
- 支持上下方向键跨行移动。
- 可显示行号。
- 可高亮当前公式行。

### 4.3 多行选择

- 鼠标拖动可跨多行选择公式内容。
- `Delete / Backspace`：删除跨行选区并连接剩余内容。
- 复制、粘贴可保留 VisualTeX 多行结构。

### 4.4 希腊字母键盘 `Ctrl+G`

- 在公式编辑区按 `Ctrl+G` 激活一次希腊字母输入。
- 随后按字母键插入对应小写希腊字母。
- `Shift + 字母`：输入对应大写形式。
- `Esc`：取消本次希腊字母输入。
- 每次 `Ctrl+G` 只处理随后一个字母。

常用映射：

| 键 | 小写 | `Shift` 大写 |
|---|---|---|
| `A` | `α` | `A` |
| `B` | `β` | `B` |
| `G` | `γ` | `Γ` |
| `D` | `δ` | `Δ` |
| `Q` | `θ` | `Θ` |
| `L` | `λ` | `Λ` |
| `M` | `μ` | `M` |
| `X` | `ξ` | `Ξ` |
| `P` | `π` | `Π` |
| `R` | `ρ` | `P` |
| `S` | `σ` | `Σ` |
| `F` | `φ` | `Φ` |
| `Y` | `ψ` | `Ψ` |
| `W` | `ω` | `Ω` |

其余映射：`E→ε`、`Z→ζ`、`H→η`、`I→ι`、`K→κ`、`N→ν`、`O→o`、`T→τ`、`U→υ`、`C→χ`。

示例：`Ctrl+G` → `A` 插入 `\alpha`。

### 4.5 `align` 自主对齐

适用格式：`align`、`align*`、`aligned`、`equation + split`、`equation* + split`。

- 将光标放到需要对齐的位置前。
- 输入 `&`。
- `&` 在可视化编辑区中不显示。
- 多行相同标记位置自动对齐。

```latex
\begin{align}
f(x) &= x^2+1 \\
f^{\prime}(x) &= 2x
\end{align}
```

### 4.6 分段函数 `cases`

- **公式工具 → 结构 → cases**：插入分段函数。
- 左列填写表达式，右列填写条件。
- `cases` 内按 `Enter`：新增一行。

```latex
f(x)=\begin{cases}
x^2 & x\ge 0 \\
-x & x<0
\end{cases}
```

### 4.7 矩阵

- **公式工具 → 矩阵**：打开矩阵工具。
- 选择定界符。
- 在 10×10 网格中选择行数和列数。
- 点击 **插入当前矩阵** 插入。
- 右键当前矩阵可绑定快捷键。

支持：`matrix`、`pmatrix`、`bmatrix`、`Bmatrix`、`vmatrix`、`Vmatrix`。

```latex
A=\begin{bmatrix}
1&2\\
3&4
\end{bmatrix}
```

### 4.8 分式、根式、上下标

- **分式**：填写分子与分母。
- **根式**：填写根号内容；可继续添加根指数。
- **上标**：插入指数位置。
- **下标**：插入下标位置。
- **上下标**：同时创建上下标。
- **占位框**：点击后输入；完成后继续移动光标。

```latex
x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}
```

### 4.9 括号与重音

- **括号**：圆括号、方括号、花括号、绝对值等。
- **自动配对定界符**：自动补全成对括号。
- **hat / bar / vec / tilde / dot**：添加重音或向量标记。

### 4.10 求和、积分与极限

- **积分**：普通积分、定积分、多重积分、围道积分。
- **求和**：`\sum` 及上下限。
- **连乘**：`\prod` 及上下限。
- **极限**：`\lim` 及趋近条件。
- **偏导**：`\partial`。
- **导数**：插入导数结构。
- **Nabla**：`\nabla`。
- **无穷**：`\infty`。

### 4.11 选区格式

先选择公式内容：

- **粗体**：切换粗体。
- **斜体**：切换斜体。
- **文字颜色**：设置选区颜色。
- **背景颜色**：设置选区背景。
- 支持预设颜色与自定义颜色。

### 4.12 右键菜单

- 公式编辑区右键：**复制 PNG 到剪贴板**。
- MathLive 原生右键菜单不显示。

## 5. 快捷输入

### 5.1 默认公式快捷键

仅在可视化公式编辑区优先生效。

| 快捷键 | 功能 |
|---|---|
| `Ctrl+R` | 根式 |
| `Ctrl+F` | 分式 |
| `Ctrl+J` | 上下标 |
| `Ctrl+L` | 下标 |
| `Ctrl+D` | 度数 |
| `Ctrl+Shift+P` | 偏微分符号 |
| `Ctrl+Shift+I` | 定积分模板 |
| `Ctrl+Shift+S` | 求和模板 |
| `Alt+Shift+X` | 下划线 X |
| `Alt+Shift+Y` | 下划线 Y |

### 5.2 自定义公式快捷键

可绑定：

- 公式工具。
- 常用公式磁贴。
- 自定义公式磁贴。
- 自定义矩阵。

设置方法：

1. 右键公式工具、磁贴或矩阵。
2. 点击 **设置快捷键**。
3. 按下组合键。
4. 点击 **绑定快捷键**。

规则：

- 快捷键必须包含 `Ctrl`、`Alt` 或系统修饰键。
- 仅 `Shift + 字母` 不可作为公式快捷键。
- 已被其他公式占用时，可覆盖原绑定。
- 系统保留快捷键不可覆盖。

### 5.3 管理公式快捷键

**设置 → 管理公式快捷键**：

- 查看全部绑定。
- 修改快捷键。
- 删除快捷键。

### 5.4 保留快捷键

以下快捷键不可被公式快捷键覆盖：

- `Ctrl+C`：复制。
- `Ctrl+X`：剪切。
- `Ctrl+V`：粘贴。
- `Ctrl+Z`：撤销。
- `Ctrl+Y` / `Ctrl+Shift+Z`：重做。
- `Ctrl+N`：新建。
- `Ctrl+O`：打开。
- `Ctrl+S`：保存 / 小键盘复制。
- `Ctrl+G`：希腊字母键盘。
- `Ctrl+,`：设置。
- `Ctrl+0`：恢复缩放。
- `Ctrl+= / Ctrl++`：放大。
- `Ctrl+-`：缩小。

### 5.5 常用数学快捷转义

**操作逻辑 → 常用数学快捷转义**：

- 控制 `alpha`、`>=`、`hat` 等快捷转义。
- **查看映射**：查看完整转换表。
- 映射表支持搜索和分类。
- 微分符号、常用函数名的正体识别独立工作。

### 5.6 光标自动跳出

可分别设置：

- 上标输入后跳出。
- 下标输入后跳出。
- 重音内容输入后跳出。
- 字体命令输入后跳出。

字体命令关闭自动跳出后，可连续输入；按 `Enter` 结束作用域。

### 5.7 命令候选

- **求和、积分等结构候选框**：大型结构候选。
- **其他命令候选框**：普通命令候选。
- `↑ / ↓`：选择候选。
- `Enter`：插入候选。
- 单击：选择。
- 双击：直接插入。

## 6. 公式工具与磁贴

### 6.1 工具分类

- **常用**：高频命令。
- **结构**：分式、根式、上下标、括号、分段函数等。
- **微积分**：积分、求和、极限、偏导、导数等。
- **矩阵**：矩阵、定界符及字体变体。
- **关系**：等于、不等、约等、大小关系等。
- **希腊字母**：希腊字母。
- **箭头**：箭头符号。
- **物理**：物理常用符号。
- **集合**：属于、包含、全称、存在等。

字体变体包括：数学粗体、黑板粗体、数学正体、大写数学花体、手写花体、数学哥特体、数学粗斜体等。

### 6.2 常用工具

- 右键普通公式工具：可 **设为常用**。
- 常用工具最多 45 个。
- 个性化排序开启后，可按使用情况调整顺序。

### 6.3 常用公式磁贴

- 点击磁贴：插入公式。
- 右键磁贴：设置快捷键。

内置示例包括：求根公式、欧拉恒等式、勾股定理、二项式定理、高斯积分、泰勒展开、质能方程、薛定谔方程、高斯定律等。

### 6.4 自定义公式磁贴

- **保存当前公式**：将当前非空公式保存为磁贴。
- **新建分区**：创建磁贴分组。
- 自定义公式最多 30 个。
- 分区最多 12 个。
- 分区可重命名。
- 删除分区会同时删除其中磁贴。

右键自定义磁贴：

- 设置 / 修改 / 清除快捷键。
- 设置磁贴颜色。
- 使用自定义颜色。
- 移动到其他分区。
- 删除磁贴。

## 8. LaTeX 源码

### 8.1 源码编辑器

- 可视化编辑区与源码实时同步。
- 支持语法高亮。
- 支持行号和自动换行。
- 可直接修改源码。
- 源码不完整或无效时显示错误状态。
- 可恢复到有效源码。
- **复制**：复制当前完整源码。
- **收起**：关闭源码区。

### 8.2 单公式代码格式

- **纯 LaTeX 源码**：不添加环境。
- **行内 · 美元符号**：`$ ... $`。
- **行内 · 圆括号**：`\( ... \)`。
- **行间 · 双美元符号**：`$$ ... $$`。
- **行间 · 方括号**：`\[ ... \]`。
- **equation**：自动编号。
- **equation***：不编号。
- **文字在公式外**：顶层文字保留在数学环境外。

### 8.3 多行代码格式

- **align**：多行；每行编号。
- **align***：多行；不编号。
- **aligned**：组合到 `\[...\]` 中。
- **gather**：多行居中；每行编号。
- **gather***：多行居中；不编号。
- **multline**：长公式多行；共用编号。
- **multline***：长公式多行；不编号。
- **equation + split**：多行；共用编号。
- **equation* + split**：多行；不编号。

### Word 原生 OMML 字体与编号（Windows）

Word 原生公式（OMML）使用适合 Word 数学排版的固定字形分工：

- 拉丁字母、拉丁扩展字符和数字：**Latin Modern Math**。
- 中文及 CJK 字符：**宋体（SimSun）**。
- 希腊字母、关系符、根号、正负号、积分号及其他数学运算符：**Cambria Math**。

VisualTeX Office 集成自带经过 SHA-256 校验的 Latin Modern Math OpenType 字体，并只把它加载到当前 `WINWORD.EXE` 进程；不会把字体写入 Windows 系统字体目录。字体文件缺失或校验失败时，VisualTeX 会明确报错，不会继续生成方框问号公式。

带编号的 OMML 行间公式使用普通 Word 段落和两个制表位：

```text
中心制表位 → 原生 Word OMath → 右对齐制表位 → (动态编号)
```

- 公式中心对准页面可写区域中心。
- 编号末端对准页面可写区域右边界。
- 编号仍由隐藏 `SEQ`、可见 `REF` 和书签维护，支持 F9 更新、动态引用和双击跳转。
- VisualTeX 不再为新 OMML 编号公式创建三列表格。
- 旧版 VisualTeX 管理的 1×3/2×3 OMML 编号表格会在编辑、重绘或更新编号时迁移为制表位段落；普通用户表格不会被自动改写。

## 11. OCR

### 11.1 公式图片 OCR

- **选择图片**：打开图片文件。
- 支持拖入图片。
- OCR 窗口打开时可直接粘贴剪贴板图片。
- **开始识别**：使用当前保存的 OCR 提供器执行识别。
- **取消识别**：停止当前本地 Worker 或远程 API 请求。
- **复制 LaTeX**：复制结果。
- **插入到光标**：插入当前公式位置。
- **追加为新行**：新建公式行并插入。
- 同一套提供器配置会同时用于主 OCR 窗口、编辑区图片粘贴、快捷 OCR、静默 OCR，以及 Word/PowerPoint 中的 OCR。

### 11.2 OCR 提供器与 API

OCR 窗口顶部可选择并保存以下提供器；默认仍为完全本地的 **PP-FormulaNet**：

- **本地 PP-FormulaNet**：图片不离开本机，使用下方选择的 S / M / L 模型。
- **OpenAI 兼容 API**：支持 **Responses API** 和 **Chat Completions** 两种协议，可填写基础地址、视觉模型、API 密钥和识别提示词。VisualTeX 以 data URL 发送图片，优先请求 JSON Schema 结构化输出；兼容服务器不支持结构化输出时会自动回退一次。
- **Ollama**：调用基础地址下的 `/api/chat`，以 base64 图片、`stream=false` 和 JSON 输出结构请求本地视觉模型。
- **Mathpix**：调用 `POST /v3/text`，使用 `app_id` / `app_key` 请求头，优先读取 `latex_styled`，缺失时读取 `text`。Mathpix 对 base64 图片限制为 2 MB，超过时 VisualTeX 会在发送前提示裁剪或压缩；请求默认携带 `metadata.improve_mathpix=false`。

OpenAI 兼容接口和 Ollama 的标准返回目标为：

```json
{
  "formulas": [
    { "latex": "x^2+y^2" }
  ]
}
```

VisualTeX 也会兼容单个 `latex` 字段、公式字符串数组、Markdown JSON 代码块，以及仅返回一段 LaTeX 的接口，并统一转换为应用内部的 `formulas[].latex` 结果。

安全规则：

- API 密钥只保存在 Windows 原生后端，使用当前 Windows 用户的 DPAPI 加密；界面重新打开时只显示“已保存”，不会回显明文。
- 留空密钥输入框会继续使用已保存密钥；勾选删除后保存才会清除。
- 除 `localhost` / `127.0.0.1` 等本机回环地址外，携带密钥的接口必须使用 HTTPS；VisualTeX 会拒绝把密钥发送到远程明文 HTTP 地址。
- 使用远程提供器时，当前图片会发送到用户填写的接口；切回本地提供器后不会发送图片。
- 修改提供器、地址、模型或密钥后必须点击 **保存提供器**，未保存配置不会参与识别。

### 11.3 本地 OCR 模型

- **M**：默认平衡模型。

### 11.6 快捷 OCR

快捷 OCR 菜单提供三种截图来源，默认使用 Windows：

- **Windows 截图工具（默认）**：直接打开 Windows 区域截图选择器。
- **PixPin**：VisualTeX 通过 PixPin 的脚本接口打开区域截图；完成后直接读取 PixPin 写入的新剪贴板图片。需要已安装或正在运行 PixPin。
- **其他截图工具 / 剪贴板**：VisualTeX 不启动截图程序，只等待下一张剪贴板图片；可配合 ShareX、Greenshot 或其他会把截图复制为图片的工具。
- 等待新图片最长 60 秒；旧剪贴板图片不会被误用。
- 截图提交后自动返回 VisualTeX，再使用当前保存的 OCR 提供器识别并插入原光标位置。

### 11.7 静默 OCR

- 开启 **静默 OCR** 后可在任意应用中使用。
- 全局快捷键：`Ctrl+Alt+O`。
- 静默 OCR 与快捷 OCR 使用同一个截图来源设置：Windows、PixPin 或等待剪贴板。
- 框选截图后在后台使用当前保存的本地模型或远程 API 提供器识别。
- 识别时显示独立进度 HUD。
- 完成后按当前 LaTeX 代码格式复制结果。

### 11.8 编辑区图片粘贴 OCR

- 在公式编辑区粘贴图片可触发 OCR。
- 使用当前保存的本地模型或远程 API 提供器。
- 识别结果插回原光标位置。
- 本地 PP-FormulaNet 模式可对深色背景图片自动反色后识别；远程 API 获取原始图片并由接口自身处理。
- 识别期间显示进度并可取消。

### Word OMML 字体与编号布局

- VisualTeX 插入或转换得到的 Word 原生 OMML 仍是可由 Word 直接编辑的 `OMath`，不会改成 OLE 或图片。
- 拉丁字母、拉丁扩展字符和数字使用 **Latin Modern Math**。VisualTeX Office 集成自带固定校验版本并随 Office MSI 安装到 Windows 字体目录；加载项还会在当前 Word 进程中验证并私有加载同一份字体，因此安装或升级后无需等待重启 Word 才能正确显示。
- 中文及 CJK 字符使用 **宋体（SimSun）**。
- 希腊字母、关系符号、根号、积分号及其他数学运算符使用 **Cambria Math**。
- 带编号的行间 OMML 使用普通 Word 段落：`居中制表位 → OMath → 右对齐制表位 → (动态编号)`。公式位于页面可写区域中心，编号右边缘固定在页面可写区域右边界。
- 编号继续由隐藏 `SEQ`、可见 `REF` 和 VisualTeX 书签维护；按 `F9`、更新编号、编辑公式、格式转换或保存重开后仍保持动态引用。
- 旧版 VisualTeX 创建的三列表格 OMML 编号，会在第一次编辑、重绘或编号整理时迁移为制表位段落；包含普通用户正文的自定义表格不会被自动拍平。
