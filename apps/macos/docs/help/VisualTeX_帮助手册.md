# VisualTeX 帮助手册

**适用版本：macOS 1.3.0**

VisualTeX 用于可视化编辑 LaTeX 公式，并与 Word、PowerPoint、WPS 文字联动；通过 VisualTeX Anywhere，也可以在任意应用中直接输入公式。

---

# 1. 主界面


## 1.1 顶部栏

从左到右：

- **主菜单**：打开文件、导出、历史、OCR、设置、帮助等功能。
- **公式工具开关**：标准布局下为 **隐藏公式工具 / 显示公式工具**；经典布局下为 **收起公式磁贴 / 展开公式磁贴**。
- **文档标题**：直接点击标题修改；保存后旁边显示 **已保存**。
- **新建**：新建空白公式文档。
- **打开**：打开 `.visualtex` / `.visualtex.json` 文档。
- **保存**（保存到本地）：保存当前 VisualTeX 文档。
- **撤销**：撤销上一步编辑。
- **重做**：恢复已撤销编辑。
- **公式历史**：打开近期公式记录。
- **图片公式识别**：打开完整 OCR 窗口。
- **设置**：打开应用设置。
- **LaTeX 格式**：打开“通用 LaTeX 格式”配置（见第 9 章）。
- **小键盘**：进入或退出小键盘模式（`⌘⇧K`）。
- **导出**：打开 Markdown / SVG / PNG 导出。
- **操作逻辑**：设置自动转义和光标跳出。
- **快捷 OCR**：截图后直接识别公式。
- **静默 OCR 开关**：开启或关闭全局 `⌘⇧O`（图标开关，没有文字）。
- **OCR 识别器**：选择本地模型或 OCR API，所有 OCR 入口共用这个选择。
- **缩小公式 / 放大公式**：调整可视化公式显示大小。

工具提示中写的 Ctrl 组合键在 macOS 上也可以用 ⌘。

## 1.2 编辑区底部栏

- **左对齐 / 居中 / 右对齐**：控制整行公式在编辑区中的位置。
- **粗体**：对选中内容切换 `\mathbf`。
- **斜体/正体**：在默认数学斜体与 `\mathrm` 正体之间切换。
- **字体颜色**：修改选中内容颜色。
- **背景颜色**：修改选中内容背景色。
- **持久化粗体输入**、**字形（自动数学字形 → 持久斜体 → 持久正体）**、**持久化字体颜色输入**、**持久化背景颜色输入**：开启后，之后输入的内容持续使用该格式。
- **LaTeX 源码（⌘\）**：展开或收起源码区。
- **复制 LaTeX 源码**：按当前 LaTeX 格式复制。


## 1.3 主菜单

菜单标题为 **VisualTeX · 公式工作区**。

- **新建公式**：新建空白文档。
- **打开文档**：打开 VisualTeX 文档。
- **保存文档**：保存 VisualTeX 文档。
- **导出…**：导出 Markdown、SVG、PNG。
- **公式历史**：打开历史记录。
- **图片公式识别**：打开完整 OCR 窗口。
- **设置**：打开设置。
- **帮助手册**：打开本手册。
- **检查更新**：检查 VisualTeX 新版本。
- **语言**：`CN` / `ENG` 切换界面语言。

# 2. 可视化公式编辑

## 2.1 基本输入

点击公式行后直接输入。

```latex
x^2+y^2=z^2
```

```latex
\frac{a+b}{c}
```

```latex
\sqrt{x+1}
```

- **Enter**：在普通公式中从当前光标位置拆分并新增公式行。
- **Shift+Enter**：在同一个公式内换行（多行对齐用这个）。
- **Ctrl+Enter** / **Option+Enter**：在光标处拆分，新行为行内 / 行间公式。
- **⌘⇧Enter**：当前公式行在行内与行间之间切换（多行公式固定为行间）。
- 以上三个快捷键可在“设置 → 公式快捷键 → 管理公式快捷键”的 **公式行** 中修改或关闭。
- 每行左侧的 `$` / `$$` 标记表示该行是行内还是行间公式，点击即可切换。
- **Tab**：移动到下一个可填写位置；候选框打开时可确认候选。
- **方向键**：移动光标或切换候选。
- **Esc**：关闭当前候选或临时输入状态。
- **粘贴图片**：在公式框中粘贴图片，直接进行 OCR。

## 2.2 命令候选

输入 `\` 开头的 LaTeX 命令时显示候选。

```latex
\frac
\sqrt
\int
\alpha
\begin{cases}
```

- 候选每页 9 个，当前页的候选标有 1–9 序号。
- **1–9**：直接选择当前页对应序号的候选。
- **↑ / ↓**：切换候选。
- **Enter / Tab**：确认当前候选。
- **Space**：确认当前候选。
- **Esc**：关闭当前候选。

启用个性化排序后，高频命令会优先显示。

## 2.3 `align` 对齐

用 **Shift+Enter** 换行的各行默认在第一个关系符（`=`、`<`、`\le`、`\to` 等）处对齐，代码中在该位置写入 `&`，无需手动输入。要在其他位置对齐时，在该位置输入 `&`，手动输入的 `&` 优先。

操作：

1. 在 **LaTeX 格式** 中把 **多行** 设为 `align`。
2. 输入第一行，按 **Shift+Enter** 在同一个公式内换行，再输入下一行。
3. 需要时，在某一行要对齐的位置输入 `&`。

示例（两行都没有输入 `&`，输出时自动在 `=` 前写入）：

```latex
a &= b+c \\
longvariable &= d-e
```

- `&` 只作为对齐标记，不显示为普通字符。
- 每一行可独立决定 `&` 的位置。
- 没有关系符、也没有输入 `&` 的行，从对齐点开始左对齐。
- 从 LaTeX 源码输入或粘贴的多行公式，按源码中的 `&` 对齐。
- **多行** 为 `gather` 时，输出不保留 `&`，各行居中。
- `&` 只在公式顶层作为 VisualTeX 多行对齐标记处理；进入 `cases`、矩阵等内部结构后按结构自身规则输入。
- **编号** 开启时输出 `align`，关闭时输出 `align*`。
- **Enter** 新建的是独立公式行，每行单独输出，不会与上一行对齐。

## 2.4 分段函数 `cases`

插入：

- **公式工具 → 结构 → 分段函数**。
- 或输入 `\begin{cases}` 并确认候选。

```latex
f(x)=\begin{cases}
x^2 & x>0\\
0 & x=0\\
-x & x<0
\end{cases}
```

**Enter 规则**：

- 光标仍在 `cases` 内：新增一个分段行。
- 光标退出 `cases` 后：新增 VisualTeX 公式行。

`cases` 内的 `&` 用于表达式列与条件列，不使用外层 `align` 的顶层对齐逻辑。

## 2.5 选中内容格式

先选中公式内容，再使用底部栏的格式按钮。

- **粗体**：切换 `\mathbf`。
- **斜体/正体**：切换默认数学斜体与 `\mathrm`。
- **字体颜色**：只修改选中内容。
- **背景颜色**：只修改选中内容；可选 **无背景**。
- **添加自定义颜色**：在颜色面板中保存颜色。
- **删除自定义颜色**：在自定义颜色列表中删除。

未选中内容时，这些按钮不是整篇公式的全局样式。需要让之后输入的内容一直带某种格式时，使用底部栏的持久化按钮。

## 2.6 公式缩放

- **缩小公式 / 放大公式**：以 5% 为步长调整，范围 20%–160%。
- `⌘0`：恢复 100%。
- `⌘+`：放大。
- `⌘-`：缩小。

缩放只影响编辑显示，不修改 LaTeX 源码。

## 2.7 复制 PNG

在可视化公式编辑区右键，选择 **复制 PNG 到剪贴板**。

PNG 使用当前：

- 数学字母字体
- 中文字体
- PNG 背景设置

# 3. 公式工具

## 3.1 工具分类

- **常用**：高频公式工具入口。
- **结构**：分数、根式、上下标、分段函数等。
- **微积分**：积分、求和、极限、导数等。
- **矩阵**：矩阵、向量、行列式、矩阵运算等。
- **关系**：等号、不等号、近似关系等。
- **希腊字母**：常用希腊字母。
- **箭头**：各类箭头。
- **物理常用**：常用物理符号与结构。
- **集合与逻辑**：集合、逻辑符号。

点击工具后，内容插入当前公式光标位置。

## 3.2 设置“常用”

操作：

1. 打开任意公式工具分类。
2. **右键**目标工具。
3. 点击 **设为常用**。
4. 工具移动到 **常用**靠前位置。

- 当前常用列表最多保留 45 项。
- “设为常用”只调整工具入口，不修改公式源码。

## 3.3 工具右键菜单

右键公式工具可使用：

- **设为常用**：将非当前常用工具提到常用列表前部。
- **设置快捷键**：绑定新的公式快捷键。
- **修改快捷键**：修改已有绑定。
- **清除快捷键**：删除该工具的绑定。

# 4. 自定义矩阵

进入 **公式工具 → 矩阵 → 自定义矩阵**。

## 4.1 矩阵边界

- **无边界**：`matrix`
- **圆括号**：`pmatrix`
- **方括号**：`bmatrix`
- **花括号**：`Bmatrix`
- **单竖线**：`vmatrix`
- **双竖线**：`Vmatrix`

## 4.2 矩阵尺寸

在尺寸网格中选择行数和列数，预览会同步变化。

确认后插入当前矩阵。

使用 **Tab** 在单元格之间移动。

## 4.3 矩阵快捷键

自定义矩阵也可绑定快捷键：

**选择尺寸和边界 → 右键当前矩阵 → 设置组合键**。

绑定后可直接插入同一尺寸、同一边界的矩阵。

# 5. 快捷键

入口：**设置 → 公式快捷键 → 管理公式快捷键**，打开“公式快捷键”窗口。窗口顶部显示已设置的数量。

窗口分为以下几节（自上而下）：

- **常用按钮**：为常用按钮设置快捷键（5.5）。
- **公式输入法**：VisualTeX Anywhere 的快捷键（16.6）。
- **Microsoft Word** / **Microsoft PowerPoint**：Office 全局快捷键（5.6）。
- **公式行**：新建行内 / 行间公式行和切换当前行（5.7）。
- **输入**：确认转义键（8.1）。
- **公式编辑器**：公式工具、磁贴、自定义矩阵的快捷键（5.1–5.4）。

## 5.1 新建公式快捷键

可绑定：

- 公式工具
- 常用公式磁贴
- 自定义公式磁贴
- 自定义矩阵

公式快捷键只在**可视化公式编辑区**生效。

1. 右键目标工具或磁贴。
2. 点击 **设置快捷键…**。
3. 按下组合键。
4. 点击 **绑定快捷键**。

组合键必须包含至少一个 `Control`、`Option` 或 `Command`；`Shift` 只能作为附加修饰键。

## 5.2 修改或删除

在“公式快捷键”窗口的 **公式编辑器** 一节中，每个绑定可：

- **修改快捷键**：重新录入组合键。
- **删除快捷键**：移除绑定。

也可直接右键原工具或磁贴进行修改、清除。

## 5.3 冲突与保留

- 系统保留快捷键不能覆盖。
- 与另一条公式快捷键重复时，界面显示冲突目标；点击 **替换并绑定** 后，新绑定替换旧绑定。
- 常用按钮快捷键优先：设为常用按钮的组合键会从公式快捷键或公式行快捷键中移过来。
- 已用作 Office 全局快捷键的组合键不能再用于常用按钮或公式输入法的全局快捷键。

受保护的快捷键包括：复制、剪切、粘贴、撤销、重做（`⇧⌘Z`、`⌘Y`）、新建、打开、保存、全选 `⌘A`、希腊字母输入 `⌘G`、设置 `⌘,`、缩放、小键盘 `⌘⇧K`、公式 / 源码切换 `⌘\`、静默 OCR `⌘⇧O`，以及 `⌘H`、`⌘Q`、`⌘W`。

## 5.4 默认公式快捷键

| 功能 | 默认快捷键 |
|---|---|
| 平方根 | `⌘R` |
| 分式 | `⌘F` |
| 添加上下标 | `⌘J` |

默认快捷键也会出现在 **公式编辑器** 一节中，可修改或删除。

## 5.5 常用按钮快捷键

**常用按钮** 一节中的动作初始均为 **未设置**。点击 **+** 后按下组合键（Esc 取消）。

- **主程序与编辑器窗口**：快捷截图识别（快捷 OCR）、打开 OCR 识别窗口、复制 LaTeX、复制为图片、显示 / 隐藏源码。
- **主程序**：导出、历史记录、显示 / 隐藏公式面板、开启 / 关闭静默 OCR、设置、帮助。
- **Office 编辑器窗口**：取消编辑（编辑器窗口）。

## 5.6 Office 全局快捷键

- PowerPoint：新建公式、行内 OMML、行间 OMML。

这是全局快捷键，仅在对应 Office 应用位于前台时执行，效果与点击 Ribbon 按钮相同。组合键必须包含 Ctrl、Option 或 Command；某些按键无法注册为 macOS 全局快捷键，录入时会提示。WPS 没有对应的快捷键。

## 5.7 公式行快捷键

| 功能 | 默认快捷键 |

| 新建行内公式行 | `Ctrl+Enter` |
| 新建行间公式行 | `Option+Enter` |
| 切换当前行的行内 / 行间 | `⌘⇧Enter` |

每项可 **修改快捷键**、**恢复默认** 或 **关闭快捷键**（关闭后显示“已关闭”）。

# 6. `⌘G` 希腊字母输入

在可视化公式编辑区：

1. 按 `⌘G`。
2. 松开后按对应字母。
3. 输入对应希腊字母。

按 `Esc` 可取消本次希腊字母输入。

## 6.1 小写

| 按键 | 输出 | 按键 | 输出 |
|---|---|---|---|
| A | `\alpha` | N | `\nu` |
| B | `\beta` | X | `\xi` |
| G | `\gamma` | O | `o` |
| D | `\delta` | P | `\pi` |
| E | `\epsilon` | R | `\rho` |
| Z | `\zeta` | S | `\sigma` |
| H | `\eta` | T | `\tau` |
| Q | `\theta` | U | `\upsilon` |
| I | `\iota` | F | `\phi` |
| K | `\kappa` | C | `\chi` |
| L | `\lambda` | Y | `\psi` |
| M | `\mu` | W | `\omega` |

小写 omicron 与拉丁字母 `o` 同形，因此输出 `o`。

## 6.2 大写

`⌘G` 后按 **Shift + 对应字母**。

例如：

- `⌘G` → `Shift+G`：`\Gamma`
- `⌘G` → `Shift+D`：`\Delta`
- `⌘G` → `Shift+W`：`\Omega`

LaTeX 中与拉丁大写字母同形的希腊字母直接使用拉丁字母。

- **所属分区**：移动到其他分区。
- **删除磁贴**

删除磁贴只删除快捷入口，不修改已插入文档的普通 LaTeX。

# 8. 操作逻辑

入口：顶部栏 **操作逻辑**。

## 8.1 输入自动转义

开启后，字母词只在按**确认转义键**时转换，而且只转换光标前的那个命令名，例如：

```text
alpha + 空格 → α
thetaalpha + 空格 → theta α（theta 不变；想转 theta 就在输入 theta 后先按一次空格）
frac + 空格 → 分式（光标进入分子）
>= → ≥（符号组合键入即转换）
```

`sin` 等函数名不转义，由自动正体排版处理。Tab、运算符、方向键等其他按键都不会触发转义。转换后紧接着按 Backspace 可恢复为键入的字母，在上下标、分式等任何结构中都有效。

确认转义键默认是 Space，可在 **设置 → 公式快捷键 → 管理公式快捷键 → 输入 → 确认转义** 中通过“设置确认转义键”修改、恢复默认或关闭。确认转义键可以是单个按键；Backspace、Delete、Enter、Esc 不能使用，不带修饰键的字母和数字也不能使用。

每个开关旁的 **查看映射** 打开“自动转义映射”，可在 **搜索输入或 LaTeX** 中查找。

**自动正体排版**是单独的开关：按 SI/ISO 规则把单位（km/h）、函数名（sin、lg(x)）、常数 e 和 i、微分 d、描述性下标（v_max）排成正体；关闭后完全不做正体判断。两个开关都不影响工具栏和候选框插入的内容。

两项默认：**开启**。

## 8.2 光标自动跳出

- **上标输入后跳出**：输入一个字符或工具栏符号后返回主公式区域。
- **下标输入后跳出**：同上。
- **重音内容输入后跳出**：适用于 `hat`、`bar`、`vec`、`tilde`、`dot` 等。
- **字体命令输入后跳出**：控制 `\mathbb{}`、`\mathbf{}`、`\mathcal{}` 等作用域。

关闭“字体命令输入后跳出”后，可连续输入多个字符，再按 **Enter** 确认字体作用域。

以上四项默认：**开启**。

# 9. LaTeX 格式

入口：顶部栏 **LaTeX 格式** 按钮，打开 **通用 LaTeX 格式**：一套持久化规则同时控制行内、行间与多行公式。

格式决定：

- 源码区域显示方式
- 复制 LaTeX 时的包装格式
- 小键盘模式 `⌘S` 的复制格式
- VisualTeX Anywhere 的 LaTeX 输出

不会改变公式的数学内容。每一行是行内还是行间，由该行左侧的 `$` / `$$` 标记决定（见 2.1）。

| 项目 | 选项 | 默认 |
|---|---|---|
| 文字 | `\text{}` / 公式外 | 公式外 |
| 行内 | `$...$` / `\(...\)` | `$...$` |
| 行间 | `$$...$$` / `\[...\]` / `equation` | `$$...$$` |
| 编号 | 开启 / 关闭 | 关闭 |
| 多行 | `gather` / `align` | `gather` |

- **文字**：行内公式中的中文等顶层文字，写成 `\text{...}` 放在公式内，或放到公式外。
- **行间**选 `equation` 时：编号开启输出 `equation`，关闭输出 `equation*`。
- **多行**：用 Shift+Enter 换行的公式输出为 `gather` 或 `align` 环境；编号关闭时为 `gather*` / `align*`。
- 多个公式行之间以空行分隔，各自按自己的行内 / 行间形式输出。

旧版本中的 `multline`、`split`、`aligned` 等格式已不再提供；旧配置会自动换算为上表中最接近的设置。

# 15. 自定义字符设计器

入口：**磁贴 → 自定义 → 字符设计器**。

用于组合 VisualTeX 内没有的数学字符，并注册为可直接输入的 LaTeX 命令。注册后可得到可在 LaTeX 文档中使用的 `\newcommand` 代码和 SVG。


## 15.1 界面

- **顶部**：标题、当前命令（未填写时显示“未命名草稿”；已注册字符显示“已注册”或“有未保存修改”）、**撤销（⌘Z）**、**重做（⌘⇧Z）**、**新建空白字符**、**已注册字符** 列表、关闭。
- **左侧**：素材（符号、字体字符、图形）。
- **中间**：画布工具栏、画布、代码面板。
- **右侧**：**属性**、**图层**、**注册** 三个标签页。

`Esc` 逐级退出：先关闭已注册字符列表，再离开文本框、回到选择工具、取消选择，最后关闭设计器。

## 15.2 基本流程

1. 从左侧加入符号、字体字符或图形。
2. 在画布上拖动、缩放、旋转，组合成新字符。
3. 在 **注册** 中选择基准字符和数学类型，填写命令。
4. 点击 **注册为命令**。
5. 在代码面板中复制 LaTeX 代码或 SVG。

## 15.3 素材

**符号**：

- 在输入框中输入 LaTeX（如 `\partial`），按 Enter 或点 **加入**。
- **搜索符号**：按命令、中英文名称和关键词查找。
- 分类：常用、微积分、希腊字母、关系、集合与逻辑、箭头、物理常用。
- “常用”中也列出已注册的自定义字符，可再次作为素材组合。
- 积分、求和等大型算子自动以显示样式（`\displaystyle`）加入。

**字体字符**：

- 字体：Cambria Math、STIX Two Math、Latin Modern Math、XITS Math、系统数学衬线回退；本机未安装的字体标有“未安装”。默认 Cambria Math。
- **正体 / 数学斜体**：默认数学斜体。
- 可按字符或 `U+` 编码搜索；分类有字母与数字、数学字母扩展、希腊字母、运算符、关系与逻辑、箭头、字母式符号、几何与技术符号。
- 字形通过 macOS Core Text 读取并转为矢量轮廓。

**图形**：线段、圆、椭圆、矩形、三角形、箭头、圆弧。

新加入的字符落在基线上，并与已有内容水平居中；图形以数学轴为中心。

## 15.4 画布与图层

画布工具栏：

- **选择与变换（V）**
- **平移画布（H，或按住空格）**
- **橡皮擦（E）**：可调 **粗细**。
- **参考字符**：x、α、∂、=、∫、Σ，可隐藏。

画布显示 **基线**、**数学轴**、**x 高度**、**大写高度** 参考线，以及字符的 TeX 盒子（宽 × 高 + 深，单位 em）。右下角可 **缩小**、**放大**、**适合字符**。

画布操作：

- 拖动图层移动；按住 Shift 只沿一个方向移动。
- 拖动四角等比缩放，按住 Shift 自由缩放；拖动四边中点只改变一个方向；对角点保持不动。
- 拖动上方旋转手柄旋转；按住 Shift 按 15° 吸附，不按 Shift 时接近 90° 的倍数会自动吸附。
- 滚轮平移，Shift+滚轮横向平移，⌘+滚轮或触控板捏合缩放。
- `⌘D` 复制图层；Delete 删除；方向键移动 0.01 em，Shift+方向键移动 0.1 em。

**图层** 标签页：最上层排在最前；每个图层可 **隐藏/显示**、**锁定/解锁**。锁定的图层仍可选中，但不能移动和缩放。

橡皮擦每一笔是一个独立的“橡皮擦轨迹”图层，擦除下方所有图形。

## 15.5 属性

- **图层名称**。
- **位置与大小**：水平位置、基线上升（em）、横向缩放、纵向缩放（%）、旋转（°）、倾斜（−60°～60°）；**锁定宽高比**（默认开启）、**水平翻转**、**垂直翻转**、**逆时针 90°**、**顺时针 90°**、**1:1**（恢复原始大小与角度）。
- 对齐：**落在基线上**、**与其他图层水平居中**、**以数学轴为中心**。
- 顺序与编辑：**上移一层**、**下移一层**、**复制图层**、**删除图层**。
- **图形**（仅图形图层）：宽度 / 长度、高度、线宽、圆角（矩形）、填充。
- **裁剪**（仅字符图层）：完整、上、中、下、左、中列、右；可用 **上中下三分**、**左中右三分** 把字符拆成三个图层。裁剪不删除原字形。
- **效果**：**空心描边**（描边粗细）、**立体挤出**（深度、方向、层数）。

## 15.6 基准字符、数学类型与上下限

在 **注册** 标签页中设置：

- **基准字符**：注册后的字符使用这个字符的 TeX 盒子，因此间距、上下标和上下限与它一致；其他图层可以超出盒子。默认 **自动（最大的正体素材）**；也可指定某个素材，或选 **无（按墨迹加边距）**。系统字体字符和旋转过的图层不能作为基准字符。
- 下方显示盒子尺寸，例如“按 \iint 的 TeX 盒子 · W × A + D em”；有斜体校正时一并显示。
- **斜体校正**：由基准字符自动测得，不能手动修改，只在数学类型为 **大型算子** 时使用。
- **数学类型**：普通字符 `\mathord`（默认）、二元运算符 `\mathbin`、关系符号 `\mathrel`、大型算子 `\mathop`、左定界符 `\mathopen`、右定界符 `\mathclose`、标点 `\mathpunct`。
- **上下限**（仅大型算子）：**自动**（默认，行间公式在上下方，行内在右侧）、**上下方 \limits**、**右侧 \nolimits**。

## 15.7 注册

- **命令**：只能由英文字母组成（a–z、A–Z），最多 48 个字母；不能与其他自定义字符、VisualTeX 或 LaTeX 已有命令重名。
- **名称（可选）**：留空时使用命令名。
- **Word 替代（可选）**：转换为 Word OMML 时用来代替该字符的 LaTeX，例如 `\approx`；不能使用其他自定义字符。
- 按钮：新字符为 **注册为命令**；修改已注册字符后为 **更新字符**；未修改时显示 **已注册**。

注册后：

- 命令进入公式输入候选（搜索“自定义字符”也能找到）。
- 在 **磁贴 → 自定义** 的“已注册字符”中出现，点击即可插入。
- 公式复制、粘贴、历史记录和重新编辑均保留原始命令。
- 自定义字符库随 **设置 → 配置备份与迁移** 一起保存和导入；换设备时需要一并迁移，否则该设备只能看到未解析的命令源码。

## 15.8 管理已注册字符

点击设计器顶部 **已注册字符**：

- 点击字符：载入并编辑。
- **复制为新草稿**：命令名后自动加 `copy`，名称后加“副本”。
- **删除** → **确认删除**：删除后，已有公式中的该命令将无法显示。重新注册同名命令或导入配置备份可以恢复显示。

磁贴区的已注册字符也可删除（再次点击确认），同时删除该字符的快捷键。

## 15.9 LaTeX 代码与 SVG

代码面板有两个标签页：

- **LaTeX \newcommand**：可直接放进 LaTeX 文档的命令定义，使用 picture 环境和 graphicx，随字号缩放。
- **SVG**：独立的 SVG，每 em 1000 单位，基线与文字基线对齐。

点击 **复制** 复制当前标签页内容。

LaTeX 代码的第一行是字符名称和命令，第二行 `% Preamble:` 列出导言区需要的宏包（总有 `amsmath`，按需加 `graphicx`、`pict2e`、`trimclip`）。若字符使用 Times 数学字体设计，还会提示配合 `newtxmath` 使用。橡皮擦和空心描边无法写进 LaTeX 代码时，面板会显示“LaTeX 代码不含：…”。

大型算子的代码直接叠加在真实的 TeX 运算符上，上下限由 TeX 自行处理。例如在 `\iint` 上加一个点：

```latex
% 带点二重积分 — VisualTeX custom symbol \dotiint
% Preamble: \usepackage{amsmath,graphicx}
\newcommand{\dotiint}{\mathop{\mathchoice
    {...}{...}{...}{...}}%
  \mskip-\thinmuskip\iint\displaylimits}
```

（`{...}` 为四种字号下叠加的内容，实际代码会完整给出。）基准字符经过缩放、旋转、裁剪或加了效果时，代码改用 `\NewDocumentCommand` 和 picture 绘制整个字符，需要 2020 年 10 月以后的 LaTeX 内核。

在 LaTeX 文档中使用：

1. 按代码第二行在导言区加载宏包。
2. 把复制的整段代码粘贴到导言区。
3. 在正文中像普通命令一样使用；大型算子后可加 `\limits` 或 `\nolimits` 改变上下限位置。

```latex
\documentclass{article}
\usepackage{amsmath,graphicx}
% 粘贴设计器复制的代码
\newcommand{\dotiint}{...}
\begin{document}
行内：$\dotiint_D f\,dA$
\[
  \dotiint_D f\,dA \qquad \dotiint\nolimits_D f\,dA
\]
\end{document}
```

## 16.1 首次设置

VisualTeX 启动时自动安装并启用公式输入法，不需要在系统设置里添加。

- 它不是键盘输入法：不出现在输入法菜单里，不参与中 / 英切换，也不改变你正在使用的输入法。只有 VisualTeX 的快捷键能打开公式。
- 第一次安装后，**安装前已经打开的应用需要重新打开一次**（或注销后重新登录），公式才能写在它的输入框里。在此之前，这些应用中按快捷键会显示浮动条，并提示“… 需重新打开 · 之后公式写在输入框里”（见 16.8）。

权限：

- **辅助功能**：只在浮动条方式下（见 16.8）插入公式时需要。首次使用时 macOS 会询问。
- **屏幕录制**：VisualTeX 会请求一次，用于读取文本框的背景色，使公式颜色与文本框一致；授权在下次启动 VisualTeX 后生效。不授权时公式使用文本框报告的颜色或系统外观颜色。

## 16.2 输入一个公式

1. 在任意应用中把光标放到要插入公式的位置。
2. 按 `⌃⌥M`（行内公式）或 `⌃⌥⇧M`（行间公式）。
3. 公式出现在光标处，大小随文本框字号变化。直接输入，与主窗口的可视化编辑方式相同。
4. 按 **Enter** 插入；按 **Esc** 取消。

- 公式打开时，下方会短暂显示标签：输出格式、当前行是“行内”或“独立”（多行时显示第几行）、将要插入内容的预览，以及“切换输出格式”的快捷键。
- 再按一次 `⌃⌥M` / `⌃⌥⇧M`，或点击别处：公式收起，内容保留，下次按快捷键时继续编辑（用 `⌃⌥⇧M` 继续时当前行改为行间）。
- **Esc**：放弃本次公式。有选区时，第一次 Esc 先取消选区。
- 公式中的 LaTeX 命令补全完成前、候选表打开时，Enter 先用于确认；在 `cases` 内 Enter 新增一行。
- 字体、自定义字符、LaTeX 格式等设置每次打开公式时从主窗口读取。
- 打开、输入和插入公式都不切换输入法：公式关闭后，输入法就是打开公式之前的那一个。

## 16.3 LaTeX 命令候选表

输入 `\` 开头的命令时，公式下方出现候选表：每列一个候选，上方是序号和命令，下方是按公式字号绘制的效果。

- 每页 9 个；**1–9** 直接选择。
- **↑ / ↓**：切换候选。
- **Enter**、**Tab** 或 **Space**：确认当前候选。
- 光标下方空间不足（例如靠近屏幕底部或程序坞）时，候选表显示在公式上方，公式仍留在原来的行里。


## 16.4 公式打开时的键盘

- 公式打开期间，按键直接交给公式，不经过当前输入法：字母按英文输入（作为变量），中文输入法不会弹出候选。
- 公式里不能输入中文；需要中文时先插入公式，再在文本框里输入。
- `⌃空格`、`⌃` + 方向键等系统快捷键照常由系统处理。

## 16.5 输出格式

Enter 时插入的内容由输出格式决定：

| 格式 | 插入内容 |
|---|---|
| LaTeX | 按主窗口 **LaTeX 格式** 输出，例如行内 `$...$`、行间 `$$...$$` |
| Markdown | 适合 Markdown 编辑器：行内 `$...$`（文字放在公式外），行间或多行用独立的 `$$...$$` 块 |
| Unicode | 用 Unicode 数学字符写成的纯文本，适合不支持公式的文本框；无法转换时插入 LaTeX |
| 图片 | PNG 图片；使用输入法时按文本框的背景色和文字颜色绘制，否则使用主窗口的 PNG 背景设置 |

- 默认 LaTeX。每个应用分别记住上次使用的格式。
- `⌃⌥O`：切换到下一种输出格式（LaTeX → Markdown → Unicode → 图片）。
- 也可为每种格式单独设置快捷键（默认未设置）。

## 16.6 公式中的快捷键

| 功能 | 默认快捷键 |
|---|---|
| 进入 / 退出公式模式（全局） | `⌃⌥M` |
| 进入 / 退出独立公式（全局） | `⌃⌥⇧M` |
| 切换到下一种输出格式 | `⌃⌥O` |
| 输出格式：LaTeX / Markdown / Unicode / 图片 | 未设置 |
| 当前行设为独立公式 | `⌃⌥D` |
| 当前行设为行内公式 | `⌃⌥I` |
| 切换行内 / 独立公式 | 未设置 |
| 截图识别公式（OCR） | `⌃⌥S` |
| 插入 / 取消 | `Enter` / `Esc` |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z` |
| 粘贴（图片自动识别） | `⌘V` |
| 新建行内 / 行间公式行 | `Ctrl+Enter` / `Option+Enter` |
| 切换当前行的行内 / 行间 | `⌘⇧Enter` |
| 同一公式内换行 | `Shift+Enter` |

- 多行公式固定为行间，设为行内时提示“多行公式保持独立公式”。
- 公式打开期间，其他 ⌘ 组合键仍由当前应用处理。

修改：**设置 → 公式快捷键 → 管理公式快捷键 → 公式输入法**。点击铅笔后按下组合键（Esc 取消）；可恢复默认或设为未设置（“进入 / 退出公式模式”不能清除）。

- 两个全局快捷键需要 Control、Option 或 Command，不能与 Office 全局快捷键重复。
- 公式中使用的快捷键不能用 Command（Command 组合键归当前应用），请用 Control 或 Option。
- 新建 / 切换公式行的快捷键与主窗口共用，在“公式行”中修改。

## 16.7 识别图片和截图

- **粘贴图片**：公式打开时按 `⌘V`，剪贴板中的图片自动识别并插入光标处；剪贴板是文字时直接粘贴。
- **截图识别**：按 `⌃⌥S`，提示“请框选要识别的公式区域（Esc 取消）”，框选后识别结果插入光标处，公式保持打开。
- 识别使用主窗口当前的 OCR 设置；使用本地模型时需要先安装 OCR 运行环境（见 11.3）。失败时显示“OCR 失败：…”。

## 16.8 输入法不可用时

以下情况 VisualTeX 改用浮动条方式：光标不在文本框里、当前应用的文本框不支持输入法，或该应用在安装公式输入法之前就已打开（浮动条会提示重新打开它）。

- 公式显示在光标所在行的浮动条中（无法取得光标位置时，放在文本框或鼠标指针处）。
- 按 Enter 时，VisualTeX 通过剪贴板和 `⌘V` 粘贴公式，随后恢复剪贴板原有内容。
- 这种方式需要 **辅助功能** 权限。未授权时浮动条显示“未授权辅助功能 · ↩ 复制”，按 Enter 只把公式复制到剪贴板，并提示“已复制 · ⌘V 粘贴”。

# 18. Office 插件安装与修复

入口：**设置 → Word 与 PowerPoint 原生加载项**。

VisualTeX 会自动安装和更新 Office 插件：

- 首次启动或升级 VisualTeX 后，如果 Word 和 PowerPoint 都没有运行，VisualTeX 直接安装或更新插件；如果正在运行，会在两者都退出后自动完成（已加载的插件无法在 Office 运行时替换）。
- PowerPoint 没有自动加载目录。安装后第一次打开 PowerPoint 时，VisualTeX 通过 PowerPoint 自带的脚本命令登记并加载 `VisualTeX.ppam`，手动添加的其他 VisualTeX 加载项会被停用。macOS 可能询问是否允许 VisualTeX 控制 PowerPoint，PowerPoint 可能询问是否启用宏。
- Word 和 PowerPoint 的插件目录属于 Microsoft。macOS 27 不再询问是否允许访问其他开发者的这类目录，而是直接阻止，只显示一条数据访问被阻止的通知。这时 VisualTeX 会提示为它打开「完全磁盘访问权限」：点「打开设置」（系统设置 > 隐私与安全性 > 文件与文件夹），为 VisualTeX 打开「完全磁盘访问权限」，然后退出并重新打开 VisualTeX，插件会自动安装。从旧版本升级时，如果列表里已有旧版 VisualTeX，先将其删除再重新添加：旧版的权限不适用于新版本。之后的版本使用同一个签名，升级后权限保持有效。
- macOS 27 之前的系统会询问「VisualTeX 想访问其他 App 的数据」，请点「允许」；也可以改为在 系统设置 > 隐私与安全性 > 完全磁盘访问权限 中打开 VisualTeX。安装、修复和卸载最多等待 90 秒，超时后可以重试，界面不会卡住。
- 在设置中卸载插件后，VisualTeX 不再自动安装，直到再次点击安装或修复。
- 安装、更新或修复插件时，VisualTeX 同时把 Word **OMML 字体**菜单使用的 STIX Two Math、Latin Modern Math 和 TeX Gyre Termes Math 安装到用户字体文件夹 `~/Library/Fonts`（见 19.13）。卸载插件不删除这些字体，已有文档可能仍在使用它们。

手动安装、修复或卸载前，先使用 `⌘Q` 完全退出 Word 和 PowerPoint。

## 18.1 状态

Word 和 PowerPoint 分别显示：

- 是否已安装（已安装 / 未找到）
- 插件文件是否为当前版本（“VisualTeX 插件文件为当前版本” / “VisualTeX 插件未安装”）
- 插件是否已加载（如“VisualTeX 已加载”）
- **安装位置**
- 安装包资源是否完整（“安装包资源完整”）

- **安装或更新插件**：首次安装或 VisualTeX 升级后使用。
- **修复插件**：插件文件缺失或加载异常时使用。
- **打开 Word** / **打开 PowerPoint**。

- **查看诊断日志**。

PowerPoint 另有 **在 PowerPoint 中加载 VisualTeX** 指引：**在 Finder 中显示 VisualTeX.ppam**、**检查 PowerPoint 是否已加载**。

自动登记失败时（例如拒绝了自动化权限），可在 PowerPoint 的 **工具 → PowerPoint 加载项**中点击 ＋，选择 `~/Library/Group Containers/UBF8T346G9.Office/VisualTeX/OfficeAddins/VisualTeX.ppam`。后续更新复用这个固定路径，不需要重新登记。

# 19. Word

Word 功能区位于 **VisualTeX** 选项卡。


## 19.1 “公式”组

- **图片行内公式**：插入 VisualTeX 图片行内公式。
- **图片行间公式**：插入 VisualTeX 图片行间公式。
- **OMML 行内公式**：插入 Word 原生行内公式。
- **OMML 行间公式**：插入 Word 原生行间公式。

也可双击 VisualTeX 公式本体进入编辑。以上四个新建按钮可设置全局快捷键（见 5.6）。

## 19.2 Word 公式编辑窗口

顶部可设置：

- **行内 / 行间**：新建时选择公式排版；编辑已有公式时不可更改。
- **行内样式**：**Text style（紧凑）** / **Display style（展开）**，仅用于 Word 图片行内公式。
- **字号**：**中文字号** 或 **磅值**。
- **添加公式编号**：Word 行间公式可用；编辑已有公式时，勾选或取消即添加或去掉编号。
- **快捷 OCR**、**OCR 识别器**、缩放。
- **撤销 / 重做**
- **取消**
- **完成并插入 / 更新公式**

完成快捷键：`⌘Enter`、`Ctrl+Enter` 或 `⌘S`。Esc 不会关闭窗口。

新建 Word 公式时，字号默认参考当前 Word 段落正文的字号。

## 19.3 “添加公式编号”记忆

只在**新建 Word 行间公式**时记忆：

- 上一次勾选：下次新建图片或 OMML 行间公式默认勾选。
- 上一次取消：下次默认取消。
- 图片公式与 OMML 共用该记忆。
- AI 助手（Office MCP）插入的公式按它要求的加或不加编号，不使用也不改变该记忆。

## 19.4 图片 / OMML 互转

- **所选格式转换**：**转为 Word OMML**（将所选 VisualTeX 图片公式转为 Word 原生 OMML）/ **转为图片公式**（将所选 Word OMML 转为 VisualTeX 图片公式）。
- **全文格式转换**：**全文图片公式 → Word OMML** / **全文 OMML → 图片公式**。

转换保留公式元数据、字号、编号和引用，不需要重新输入 LaTeX。

## 19.5 更新公式编号

点击 **更新公式编号**。

用于：

- 中间插入编号公式
- 删除编号公式
- 移动编号公式
- 修改编号格式
- 修复旧的异常编号结构

编号按当前文档顺序重新整理，并同步关联引用。编辑带编号的公式时编号保持不变；手动设置过格式的编号也会保留。

## 19.6 编号格式

**编号格式**菜单：

- **顺序编号 (1)**
- **按章编号 (2.1)**
- **按章编号 (2-1)**
- **按节编号 (2.3.1)**
- **按节编号 (2.3-1)**

选择后立即应用到当前文档，并记为后续新文档的默认编号格式。

不要直接手工修改公式右侧编号文字。

图片公式的编号使用公式的字号；KaTeX 公式的编号使用 Cambria Math，Times New Roman 公式的编号使用 Times New Roman。OMML 公式的编号使用 Cambria Math。手动修改编号的字号、字体或颜色后，移动光标或重新打开文档不会还原；修改公式字号时，编号随公式一起改变并重新对齐。

## 19.7 批量编号

**批量编号**菜单：

- **为所选行间公式编号**：为所选内容涉及的段落中尚未编号的行间公式添加编号；光标放在公式所在行时只处理该公式。
- **为全文行间公式编号**：为全文所有尚未编号的行间公式添加编号。

说明：

- 图片公式与 Word OMML 公式按当前编号格式各自编号。
- 已有编号保持不变，其后的编号自动顺延，正文引用同步更新。
- 表格中的公式、与正文同处一段的公式和旧版格式的公式不处理，开始前会提示数量；旧版格式可先点击 **更新公式格式**。
- 一次撤销即可恢复。

## 19.8 更新公式格式

**更新公式格式**：把旧版 VisualTeX 创建的编号和公式标记升级为当前格式。一次撤销即可恢复。

同时用当前设置的字体（数学字体、中文字体、字母/希腊字母/数字字体）按公式保存的 LaTeX 重绘字体与之不同的 VisualTeX 公式：公式的 ID、编号、引用、字号和行内/行间形式不变。开始前列出要重绘的公式数量和当前字体；没有字体记录的旧公式按未设字母/希腊字母/数字字体处理。

同时统一 OMML 公式的字体：

- 在 **OMML 字体**（19.13）中选了字体时，先把它设为文档的数学字体；选“跟随文档”时保留文档原来的数学字体。
- 选的是 **Latin Modern Math** 时，文档数学字体设为 VisualTeX Latin Modern Math；以前使用原版 Latin Modern Math 的文档和公式一起改用它（字形相同，与 Windows 版 VisualTeX 使用的字体一致）。
- 每个 OMML 公式中指定了其他字体的数学文字改为文档数学字体；公式中的普通文本（如 `\mathrm`、`\text`）保留原来的文字字体。
- 公式编号（# 与编号字段）和 VisualTeX 元数据不变。
- 确认框和完成提示分别显示将要改变和已经改变的公式数。

## 19.9 中间插入编号公式

1. 将 Word 光标放在两个已有公式之间。
2. 新建行间公式并勾选 **添加公式编号**。
3. 插入完成后点击 **更新公式编号**。

后续公式编号按文档位置顺延。

## 19.10 插入公式引用

1. 将 Word 光标放到正文引用位置。
2. 点击 **插入公式引用**。
3. 在 **Word OMML 公式** 或 **图片公式** 子菜单中点击目标编号公式，引用立即插入。

插入结果使用 Word `REF` 字段，不是手写数字。

中间插入、删除或移动公式后，点击 **更新公式编号**即可同步正文引用。

## 19.11 批量导入

点击 **批量导入**。

用于把 Markdown / LaTeX 文档一次导入 Word。

流程：

1. 粘贴或导入 `.md` / `.tex`。
2. 查看结构预览。
3. 如需统一编号，可勾选 **行间公式全部编号**；也可继续单独调整公式卡片。
4. 点击导入 Word。

批量编号只作用于行间公式，行内公式不会添加编号。公式卡片可设置：

- 行内 / 行间
- 是否编号
- 字号
- Word OMML / 图片公式

正文可解析标题、列表、正文、代码块和混合公式。

## 19.12 LaTeX 重绘

### 重绘所选

- **重绘为 Word OMML**
- **重绘为 VisualTeX 图片公式**
- **将 OMML 公式转为 LaTeX**
- **将图片公式转为 LaTeX**

只处理当前选区。

### 重绘全文

- **全文重绘为 Word OMML**
- **全文重绘为 VisualTeX 图片公式**
- **将全文 OMML 公式转为 LaTeX**
- **将全文图片公式转为 LaTeX**

扫描当前 Word 正文并处理整篇文档。

可识别常见 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 和常见公式环境。

## 19.13 公式字号

Word 功能区 **所选公式字号**用于修改一个或多个已选中的 VisualTeX 图片公式。菜单第一项显示当前字号（如“当前: 五号 (10.5 pt)”），其后为八号到初号和 48、54、72、96 磅。

选择字号后立即应用。带编号的公式，编号的字号随公式改变，公式与编号重新居中对齐。

**行内公式字号**和**行间公式字号**分别设置行内公式和行间公式的字号：

- 选择一个字号后，当前文档中所有行内（或行间）公式立即改为这个字号，包括 VisualTeX 图片公式和 Word 公式；带编号的公式算作行间公式。一次撤销即可恢复。
- 这个字号同时用于之后的 LaTeX 重绘（所选内容或全文）、批量导入，以及 OMML 与图片公式之间的格式转换（所选公式或全文）。
- 设置对所有文档生效，重新启动 Word 后仍然保留。
- 选“跟随正文”不改动现有公式；之后重绘和批量导入跟随正文字号，格式转换保留每个公式原来的字号。
- 新建公式（“公式”组的按钮）不受影响，仍然参考当前段落正文的字号。
- 批量导入窗口中手动改过字号的公式，保留手动设置的字号。

**OMML 字体**选择 Word 原生公式（OMML）使用的数学字体：

- **跟随文档（不更改）**：默认。VisualTeX 写入的公式使用文档当前的数学字体，不改动文档。
- **Cambria Math**、**STIX Two Math**、**Latin Modern Math**、**TeX Gyre Termes Math**：选择后，当前文档的数学字体立即改为这个字体，现有 OMML 公式一起改用它（规则同 19.8）。一次撤销即可恢复。之后新建、编辑、重绘、导入和格式转换写入的 OMML 公式都先把这个字体设为文档数学字体再写入。
- Cambria Math 随 Office 提供。另外三种字体随 VisualTeX 提供，无需手动安装：安装、更新或修复 Office 插件时，VisualTeX 把它们复制到用户字体文件夹 `~/Library/Fonts`。已有相同的文件时不重复复制；其他文件名的字体（例如自己安装的同名字体）不会被删除或覆盖。字体复制失败只记入诊断日志，不影响插件安装。
- 三种字体都是 TrueType 版本，Word 中的字体名分别为 `STIX Two Math`（官方 TrueType 版）、`VisualTeX Latin Modern Math` 和 `VisualTeX TeX Gyre Termes Math`（由 Latin Modern Math 和 TeX Gyre Termes Math 转为 TrueType 轮廓，字形和数学排版数据不变）。Windows 版 VisualTeX 使用相同的字体名，同一文档在两个平台上显示相同的字体。
- Word 中没有的字体标有“（未安装）”并且不能选择。新安装的字体在重新启动 Word 后才能选择。
- 以前选择的 Latin Modern Math 继续有效：Word 中有 VisualTeX Latin Modern Math 时改用它，只有原版 Latin Modern Math 时仍使用原版。
- 设置对所有文档生效，重新启动 Word 后仍然保留。打开其他文档时不会自动改动，写入公式或执行“更新公式格式”时才应用。
- 图片公式和 PowerPoint 不受影响。WPS 文字中的 **WPS公式字体**是同一个设置（见 21.2）。

## 19.14 打开 VisualTeX

**打开 VisualTeX**（位于“转换与编号”组）：只打开主应用，不新建公式。

## 19.15 修复行间公式

**修复行间公式**（“兼容修复”组）：检查全文的行间公式（图片公式和 Word OMML 公式），把全文排版改动（全选后设置缩进或行距、清除格式、套用样式、格式刷、项目符号）打乱的放回原位：

- 清除缩进（含首行缩进 2 字符）、项目符号和编号。
- 带编号的图片公式：恢复所在栏或单元格的居中/右对齐制表位和公式前的制表符，对齐方式改回两端对齐。
- 不带编号的图片公式和 OMML 公式：改回居中。
- 固定行距改为同值的“最小值”，高公式不再被截断；其他行距保持不变。
- 图片公式被“清除格式”去掉的垂直位置按 VisualTeX 的排版恢复。

只改这些公式所在段落的格式和图片的垂直位置，公式内容、字号、编号（包括编号的字体）和引用不变。全部修改一次撤销；没有需要修复的公式时不改文档。完成后报告检查和修复的公式数及各类问题的数量。MathType 公式和 Windows 版 VisualTeX 的 OLE 公式不在 Mac 上处理。

# 20. PowerPoint

PowerPoint 功能区位于 **VisualTeX** 选项卡。

## 20.1 “公式”组

- **行内 OMML** / **行间 OMML**：在文本框的插入位置插入 PowerPoint 原生公式，字号使用插入位置文字的字号（编辑窗口中的字号不可改）。
- **新建 SVG 公式**（见 20.3）和 **编辑所选公式**（见 20.4）也在这一组。

## 20.2 LaTeX 重绘

三个菜单都有 **所选**、**本页**、**全部** 三项：

- **所选**：选中的文字、文本框或左侧缩略图中的幻灯片；只有光标时为光标所在的文本框。
- **本页**：当前幻灯片。
- **全部**：整个演示文稿，开始前会确认。

功能：

- **LaTeX → OMML**：把文本框中完整的 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 和常见公式环境原位换成 PowerPoint 原生公式，字号跟随所在文字；`$$...$$` 和 `\[...\]` 成为单独一段、居中的行间公式。选中部分文字时，只处理完全在选区内的公式。
- **LaTeX → VisualTeX**：只含一个公式的文本框换成中心位置相同的 VisualTeX SVG 公式。与文字混排的公式保持不变，结束时会列出，请改用 **LaTeX → OMML**。
- **转为 LaTeX 代码**：原生公式原位换成 `$...$`（单独成段时为 `$$...$$`），其余文字不变；VisualTeX 公式换成中心位置相同、内容为 `$$...$$` 的文本框，之后可以再次重绘。光标位于某个原生公式中时，只转换这个公式。

表格和组合中的文字不处理。个别公式无法写入时（例如处理期间文本框被修改），其余公式照常写入，结束时会说明哪些公式没有写入。

## 20.3 新建 SVG 公式

点击 **新建 SVG 公式**打开 VisualTeX 公式编辑窗口，新建 SVG 公式，默认字号在 **设置 → PowerPoint 公式默认值** 中设置。

完成后点击 **完成并插入**（`⌘Enter`、`Ctrl+Enter` 或 `⌘S`）。

## 20.4 编辑所选公式

选中一个 VisualTeX 公式后：

- 点击 **编辑所选公式**；或
- 双击公式。

修改后点击 **更新公式**。

## 20.5 删除所选公式

**删除所选公式**、**SVG 公式字号**和 **打开 VisualTeX** 在“公式工具”组中排成一列；同组还有大按钮 **更新公式格式**（见 20.8）。


点击 **删除所选公式**删除当前选中的 VisualTeX 公式。

## 20.6 SVG 公式字号

先选中一个或多个 VisualTeX SVG 公式，再从 **SVG 公式字号**选择字号。

应用后保持公式的：

- 中心位置
- 旋转
- 层级

## 20.7 打开 VisualTeX

**打开 VisualTeX**：打开主应用。

## 20.8 更新公式格式

点击 **更新公式格式**，用当前设置的字体（数学字体、中文字体、字母/希腊字母/数字字体）按公式保存的 LaTeX 重绘字体与之不同的 VisualTeX 公式。开始前列出公式数量和当前字体。

重绘后保持公式的：

- 中心位置和显示大小
- 旋转
- 层级和名称

公式内容不变，一次撤销即可恢复。没有字体记录的旧公式按未设字母/希腊字母/数字字体处理。

# 21. WPS Office

VisualTeX 为 macOS 版 WPS 文字和 WPS 演示提供 **VisualTeX** 选项卡。

## 21.1 安装

入口：**设置 → WPS Office 加载项**。

- VisualTeX 启动约 4 秒后自动安装或更新 WPS 加载项。WPS 需要先打开过一次才会被识别。
- 每个 WPS 版本一张卡片（“WPS Office”或“WPS Office（国际版）”），显示：WPS 是否已安装、加载项是否已安装或需要更新、是否已准备好与 WPS 连接（端口）、**安装位置**。
- 按钮：**安装或更新 WPS 加载项**、**打开 WPS**、**卸载 WPS 加载项**；卸载后不再自动安装，直到再次安装。
- WPS 第一次加载这个加载项时会先后询问两次，请先选择「允许」，再选择「确定」。
- 使用时请保持 VisualTeX 处于打开状态。VisualTeX 没有运行时，点击按钮会提示先打开 VisualTeX。
- macOS 阻止访问 WPS 加载项文件夹时，按提示为 VisualTeX 打开「完全磁盘访问权限」。


## 21.2 WPS 文字中的功能

选项卡与 Word 相同（同样的组、按钮和排列；Word 写 OMML 的地方写“WPS 公式”，即 WPS 自己的公式）：

- **公式**：图片行内、图片行间、WPS行内、WPS行间、编辑所选；双击公式也可编辑。WPS for Mac 的大按钮名称只显示一行，所以名称较短，鼠标停留时显示完整名称（如“插入 WPS 行内公式”）。
- **转换与编号**：所选格式转换（转为 WPS 公式、转为图片公式）、全文格式转换、更新公式格式；更新公式编号、编号格式、插入公式引用；批量编号、批量导入、打开 VisualTeX。
- **LaTeX 重绘**：重绘所选、重绘全文。
- **公式字号**：所选公式字号、行内公式字号、行间公式字号；**WPS公式字体**与 Word 的 **OMML 字体**（见 19.13）是同一个设置。WPS 没有文档数学字体，VisualTeX 把所选字体写进它插入、编辑、转换或重绘的每个 WPS 公式，已有公式再次编辑后改用它；三种内置数学字体随 WPS 加载项一起装入 `~/Library/Fonts`，macOS 中没有的字体不能选择。
- **兼容修复**：修复行间（即 **修复行间公式**，见 19.15；WPS 公式与 OMML 公式同样处理）。

公式在与 Word 相同的编辑窗口中编辑。文档在 WPS 与 Word 之间往返后仍可继续编辑公式；Word 打开 WPS 保存的文档时，会自动修复损坏的编号。

限制：一次全文格式转换最多处理 1000 个公式；重绘的源文本最大 5 MB。

## 21.3 WPS 演示中的功能

选项卡与 PowerPoint 相同（PowerPoint 写 OMML 的地方写“WPS 公式”，大按钮名称较短，鼠标停留时显示完整名称）：

- **公式**：行内WPS、行间WPS、新建SVG、编辑所选；双击公式也可编辑。
- **LaTeX 重绘**：LaTeX→WPS、LaTeX→VisualTeX、转为LaTeX，各有所选、本页、全部（见 20.2）。
- **公式工具**：更新格式（即 **更新公式格式**，见 20.8；WPS 演示把每个公式的修改各记为一步撤销）、删除所选公式、SVG 公式字号、打开 VisualTeX。

在 WPS 文字中，**更新公式格式** 同样用当前字体重绘字体与之不同的 VisualTeX 公式（见 19.8）。

在 WPS 演示中插入的 SVG 公式，在 PowerPoint 中打开后也可以编辑。写入原生公式时 VisualTeX 会临时使用剪贴板，完成后恢复原来的内容。

# 23. 容易混淆的功能

## 常用工具 vs 常用磁贴 vs 自定义磁贴

- **常用工具**：已有公式结构或命令的高频入口。
- **常用磁贴**：从公式库选择的完整公式。
- **自定义磁贴**：用户保存的完整公式行。

## 整行对齐 vs `align` 对齐

- **左 / 中 / 右对齐**：控制整行公式在编辑区的位置。
- **`align` 的 `&`**：控制多行公式内部共同对齐点。

## 保存 vs 复制 LaTeX vs 导出

- **保存**：生成可继续编辑的 VisualTeX 文档。
- **复制 LaTeX**：按当前 LaTeX 格式复制源码到剪贴板。
- **导出**：生成 Markdown、SVG、PNG 外部文件。

## 图片公式 vs OMML

- **图片公式**：VisualTeX 渲染结果，适合保持统一视觉样式。
- **OMML**：Word 原生公式，可直接使用 Word 原生公式工具编辑。

## 静默 OCR vs Anywhere 截图识别

- **静默 OCR（`⌘⇧O`）**：识别结果复制到剪贴板。
- **Anywhere 截图识别（`⌃⌥S`）**：在打开的公式中使用，识别结果直接插入公式光标处。

# 24. 文档文件

文档模式的文档是普通的 Markdown 文件（`.md`）。

## 24.1 文档文件夹

- 默认位置：`文档\VisualTeX`（macOS：`文稿/VisualTeX`）。
- 文档库列出该文件夹中的 `.md`、`.markdown` 文件；文档库的文件夹就是它的子文件夹，文档名就是文件名。
- 文档库顶部的 **文档文件夹** 按钮可改用其他文件夹；原文件夹中的文件不动。
- 删除的文档移入该文件夹下隐藏的 `.trash`，30 天后清除；在 **最近删除** 中可恢复或立即删除。
- 文档的右键菜单：**重命名**、**创建副本**、**移到**、**导出**、**在访达中显示**、**删除**。

## 24.2 新建、打开、保存

| 操作 | 说明 |
| --- | --- |
| **新建文档**（`⌘N`） | 在文档文件夹中新建 `未命名文档.md` |
| **打开文档**（`⌘O`） | 打开任意位置的 `.md`、`.markdown`、`.vtxdoc`，在原位置编辑；`.zip`（Markdown 导出包）和 `.json` 复制进文档文件夹（压缩包中的图片与文档文件夹中已有的图片重名时，文档和图片放入以文档命名的新文件夹） |
| **保存文档**（`⌘S`） | 立即写入文件；编辑停顿后也会自动保存 |
| **另存为…**（`⇧⌘S`） | 另存为一个 Markdown 文件并转到该文件 |
| **导出 Markdown** / **导出 PDF** | 导出副本，当前文档不变 |

- 在文档文件夹之外打开的文件列在文档库的 **最近打开** 中；**从列表移除** 不删除文件，也不删除 VisualTeX 为它记住的格式（再次打开时恢复）。
- 在访达中对 `.md` 文件选择 **打开方式 → VisualTeX**，或把文件拖到 VisualTeX 窗口，也会在原位置打开。VisualTeX 不会把自己设为 `.md` 的默认程序。

## 24.3 文件内容

- 文件中只有 Markdown：正文、`$…$` 行内公式、`$$` 行间公式、表格、`![说明](路径)` 图片、`[^1]` 脚注。
- 标题写成 `# 标题`；作者、日期、摘要、题注是普通文本行；带编号的公式写入 `\tag{n}`。
- 其他程序写的 Markdown 文件，未改动的行按原样保留（包括换行符、编码和 BOM）；改动一行只改写这一行。
- 图片是文件：其他程序写入的图片路径保持不变；新插入的图片存入文档旁的 `assets` 文件夹，使用原文件名，粘贴的图片命名为 `image-日期-时间.png`。

## 24.4 VisualTeX 记住的格式

Markdown 没有对应语法的内容不写入文件，由 VisualTeX 另行记住，再次用 VisualTeX 打开时恢复：

- 页面设置、字体、行距、公式编号格式、章节编号；
- 页面命令（`\newpage`、`\pagenumbering` 等）：在 VisualTeX 中插入的页面命令不写入文件，随其后一行记住；文件自己写有的这类命令行保持原样；
- 文字颜色、字号、底色，段落对齐和缩进；
- 哪一行是标题、作者、日期、摘要、题注；公式是否自动编号；图片宽度与环绕；表格的合并单元格、列宽和线型。

记录的位置：

- 文档文件夹中的文档：该文件夹下隐藏的 `.visualtex` 子文件夹。移动或同步整个文档文件夹时一并带走。
- 其他位置的文件：VisualTeX 的应用数据目录。文件在 VisualTeX 之外被移动或改名后，只要内容未变，仍能找回记录。

格式按行的文字对应。某一行被其他程序改写后，只有这一行的格式失效，其余保留。在 VisualTeX 中重命名、移动、创建副本、删除文档时，记录和图片随文档一起处理。

## 24.5 文件被其他程序修改

- 文件在磁盘上被修改，而 VisualTeX 中没有未保存的改动：回到 VisualTeX 窗口时自动重新载入。
- 两边都有改动：VisualTeX 询问 **重新载入**（放弃这里的改动）、**覆盖**（写入这里的版本）或 **另存副本**（这里的版本存为新文件，原文件保持磁盘上的内容）。

## 24.6 章节编号

新文档和打开的 Markdown 文件，章节标题默认不编号。在文档工具栏 **编号格式** 的 **章节编号** 中可选择 `1  1.1`、`1.  1.1.` 或 **无**。

## 24.7 旧版文档（`.vtxdoc`）

- 升级后首次进入文档模式时，旧文档库中的文档逐个转换为文档文件夹中的 `.md` 文件；每个文档转换后都会读回并与原文档比较。
- 无法精确转换的文档以 `.vtxdoc` 原样放入文档文件夹，并提示一次；`.vtxdoc` 仍可打开和编辑，用 **另存为…** 可存为 Markdown。
- 原文档库保留在应用数据目录中，不会删除。
