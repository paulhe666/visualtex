# VisualTeX 帮助手册

**适用版本：macOS 1.2.5**

VisualTeX 用于可视化编辑 LaTeX 公式，并与 Word、PowerPoint 联动。

---

# 1. 主界面

## 1.1 顶部栏

- **主菜单**：打开文件、导出、历史、OCR、设置、帮助等功能。
- **公式工具/磁贴开关**：显示或隐藏侧边工具区；经典布局下控制公式磁贴区。
- **文档标题**：直接点击标题修改。
- **新建**：新建空白公式文档。
- **打开**：打开 `.visualtex` / `.visualtex.json` 文档。
- **保存**：保存当前 VisualTeX 文档。
- **撤销**：撤销上一步编辑。
- **重做**：恢复已撤销编辑。
- **公式历史**：打开近期公式记录。
- **图片公式识别**：打开完整 OCR 窗口。
- **设置**：打开应用设置。
- **LaTeX 代码格式**：设置源码显示与复制格式。

## 1.2 编辑区顶部

- **左对齐 / 居中 / 右对齐**：控制整行公式在编辑区中的位置。
- **粗体**：对选中内容切换 `\mathbf`。
- **斜体/正体**：在默认数学斜体与 `\mathrm` 正体之间切换。
- **字体颜色**：修改选中内容颜色。
- **背景颜色**：修改选中内容背景色。
- **导出**：打开 Markdown / SVG / PNG 导出。
- **操作逻辑**：设置自动转义、光标跳出、候选框。
- **快捷 OCR**：截图后直接识别公式。
- **静默 OCR**：开启或关闭全局 `⌘⇧O`。
- **OCR 模型**：选择粘贴图片、快捷 OCR 使用的模型。
- **缩放**：调整可视化公式显示大小。
- **小键盘**：进入或退出小键盘模式。

## 1.3 主菜单

- **新建公式**：新建空白文档。
- **打开文档**：打开 VisualTeX 文档。
- **保存文档**：保存 VisualTeX 文档。
- **导出**：导出 Markdown、SVG、PNG。
- **公式历史**：打开历史记录。
- **图片公式识别**：打开完整 OCR 窗口。
- **设置**：打开设置。
- **新手教程**：重新查看快速引导。
- **帮助手册**：打开本手册。
- **检查更新**：检查 VisualTeX 新版本。
- **语言**：切换中文 / English。

# 2. 可视化公式编辑

## 2.1 基本输入

点击公式行后直接输入。

```latex
x^2+y^2=z^2
```

```latex
\frac{a+b}{c}
```

```latex
\sqrt{x+1}
```

- **Enter**：在普通公式中从当前光标位置拆分并新增公式行。
- **Tab**：移动到下一个可填写位置；候选框打开时可确认候选。
- **方向键**：移动光标或切换候选。
- **Esc**：关闭当前候选或临时输入状态。
- **粘贴图片**：在公式框中粘贴图片，直接进行 OCR。

## 2.2 命令候选

输入 LaTeX 命令时显示候选。

```latex
\frac
\sqrt
\int
\alpha
\begin{cases}
```

- **↑ / ↓**：切换候选。
- **Enter / Tab**：确认当前候选。
- **Space**：部分原生命令候选可用空格确认。
- **Esc**：关闭当前候选。

启用个性化排序后，高频命令会优先显示。

## 2.3 `align / align*` 自主对齐

`align` 不自动寻找等号。**对齐点由用户输入 `&` 指定。**

操作：

1. 将 **LaTeX 代码格式**切换为 `align`、`align*`、`aligned` 或需要显式对齐点的多行格式。
2. 在每一行需要对齐的位置直接输入 `&`。
3. 按 **Enter** 新建下一行。
4. 在下一行对应位置再次输入 `&`。

示例：

```latex
a &= b+c \\
longvariable &= d-e
```

- `&` 只作为对齐标记，不显示为普通字符。
- 每一行可独立决定 `&` 的位置。
- 不输入 `&` 时，该行没有自主对齐点。
- `&` 只在公式顶层作为 VisualTeX 多行对齐标记处理；进入 `cases`、矩阵等内部结构后按结构自身规则输入。
- `align`：每行自动编号。
- `align*`：不编号。

## 2.4 分段函数 `cases`

插入：

- **公式工具 → 结构 → 分段函数**。
- 或输入 `\begin{cases}` 并确认候选。

```latex
f(x)=\begin{cases}
x^2 & x>0\\
0 & x=0\\
-x & x<0
\end{cases}
```

**Enter 规则**：

- 光标仍在 `cases` 内：新增一个分段行。
- 光标退出 `cases` 后：新增 VisualTeX 公式行。

`cases` 内的 `&` 用于表达式列与条件列，不使用外层 `align` 的顶层对齐逻辑。

## 2.5 选中内容格式

先选中公式内容，再使用顶部格式按钮。

- **粗体**：切换 `\mathbf`。
- **斜体/正体**：切换默认数学斜体与 `\mathrm`。
- **字体颜色**：只修改选中内容。
- **背景颜色**：只修改选中内容。
- **添加自定义颜色**：点击颜色面板中的 `+` 保存颜色。
- **删除自定义颜色**：在自定义颜色列表中删除。

未选中内容时，不应把这些按钮当作整篇公式的全局样式设置。

## 2.6 公式缩放

- **−**：缩小公式显示。
- **+**：放大公式显示。
- `⌘0`：恢复 100%。
- `⌘+`：放大。
- `⌘-`：缩小。

缩放只影响编辑显示，不修改 LaTeX 源码。

## 2.7 复制 PNG

在可视化公式编辑区右键，选择 **复制 PNG**。

PNG 使用当前：

- 数学字母字体
- 中文字体
- PNG 背景设置

# 3. 公式工具

## 3.1 工具分类

- **常用**：高频公式工具入口。
- **结构**：分数、根式、上下标、分段函数等。
- **微积分**：积分、求和、极限、导数等。
- **矩阵**：矩阵、向量、行列式、矩阵运算等。
- **关系**：等号、不等号、近似关系等。
- **希腊字母**：常用希腊字母。
- **箭头**：各类箭头。
- **物理常用**：常用物理符号与结构。
- **集合与逻辑**：集合、逻辑符号。

点击工具后，内容插入当前公式光标位置。

## 3.2 设置“常用”

操作：

1. 打开任意公式工具分类。
2. **右键**目标工具。
3. 点击 **设为常用**。
4. 工具移动到 **常用**靠前位置。

- 当前常用列表最多保留 45 项。
- “设为常用”只调整工具入口，不修改公式源码。
- 当前版本没有单独的“从常用移除”右键项。

## 3.3 工具右键菜单

右键公式工具可使用：

- **设为常用**：将非当前常用工具提到常用列表前部。
- **设置快捷键**：绑定新的公式快捷键。
- **修改快捷键**：修改已有绑定。
- **清除快捷键**：删除该工具的绑定。

# 4. 自定义矩阵

进入 **公式工具 → 矩阵 → 自定义矩阵**。

## 4.1 矩阵边界

- **无边界**：`matrix`
- **圆括号**：`pmatrix`
- **方括号**：`bmatrix`
- **花括号**：`Bmatrix`
- **单竖线**：`vmatrix`
- **双竖线**：`Vmatrix`

## 4.2 矩阵尺寸

在尺寸网格中选择行数和列数，预览会同步变化。

确认后插入当前矩阵。

使用 **Tab** 在单元格之间移动。

## 4.3 矩阵快捷键

自定义矩阵也可绑定快捷键：

**选择尺寸和边界 → 右键/快捷键入口 → 设置组合键**。

绑定后可直接插入同一尺寸、同一边界的矩阵。

# 5. 公式快捷键

VisualTeX 支持为以下项目绑定快捷键：

- 公式工具
- 常用公式磁贴
- 自定义公式磁贴
- 自定义矩阵

快捷键只在**可视化公式编辑区**优先生效。

## 5.1 新建快捷键

1. 右键目标工具或磁贴。
2. 点击 **设置快捷键**。
3. 按下组合键。
4. 点击 **绑定快捷键**。

组合键必须包含至少一个：

- `Ctrl`
- `Option/Alt`
- `Command`

`Shift` 可作为附加修饰键，但不能单独作为公式快捷键修饰键。

## 5.2 修改或删除

入口：**设置 → 公式快捷键 → 管理公式快捷键**。

每个绑定可：

- **修改**：重新录入组合键。
- **删除**：移除绑定。

也可直接右键原工具或磁贴进行修改、清除。

## 5.3 冲突规则

- 系统保留快捷键不能覆盖。
- 与另一条公式快捷键重复时，界面显示冲突目标。
- 点击 **替换并绑定** 后，新绑定替换旧绑定。

受保护的常用快捷键包括复制、剪切、粘贴、撤销、重做、新建、打开、保存、希腊字母输入、设置、缩放等。

## 5.4 默认公式快捷键

| 功能 | 默认快捷键 |
|---|---|
| 平方根 | `⌘R` |
| 分式 | `⌘F` |
| 添加上下标 | `⌘J` |
| 下标 | `⌘L` |
| 角度 | `⌘D` |
| 偏微分符号 | `⇧⌘P` |
| 定积分模板 | `⇧⌘I` |
| 求和 | `⇧⌘S` |
| 下划线 X | `⌥⇧X` |
| 下划线 Y | `⌥⇧Y` |

默认快捷键也会出现在 **管理公式快捷键** 中，可修改或删除。

# 6. `⌘G` 希腊字母输入

在可视化公式编辑区：

1. 按 `⌘G`。
2. 松开后按对应字母。
3. 输入对应希腊字母。

按 `Esc` 可取消本次希腊字母输入。

## 6.1 小写

| 按键 | 输出 | 按键 | 输出 |
|---|---|---|---|
| A | `\alpha` | N | `\nu` |
| B | `\beta` | X | `\xi` |
| G | `\gamma` | O | `o` |
| D | `\delta` | P | `\pi` |
| E | `\epsilon` | R | `\rho` |
| Z | `\zeta` | S | `\sigma` |
| H | `\eta` | T | `\tau` |
| Q | `\theta` | U | `\upsilon` |
| I | `\iota` | F | `\phi` |
| K | `\kappa` | C | `\chi` |
| L | `\lambda` | Y | `\psi` |
| M | `\mu` | W | `\omega` |

小写 omicron 与拉丁字母 `o` 同形，因此输出 `o`。

## 6.2 大写

`⌘G` 后按 **Shift + 对应字母**。

例如：

- `⌘G` → `Shift+G`：`\Gamma`
- `⌘G` → `Shift+D`：`\Delta`
- `⌘G` → `Shift+W`：`\Omega`

LaTeX 中与拉丁大写字母同形的希腊字母直接使用拉丁字母。

# 7. 公式磁贴

公式磁贴用于重复插入完整公式或公式模板。

## 7.1 常用磁贴

内置磁贴包括：

- 一元二次方程求根公式
- 欧拉恒等式
- 勾股定理
- 二项式定理
- 高斯积分
- 泰勒展开
- 质能方程
- 含时薛定谔方程
- 高斯定律
- 矩阵特征方程

点击磁贴直接插入。

右键常用磁贴可设置快捷键。

## 7.2 自定义磁贴

入口：**磁贴 → 自定义**。

保存当前公式：

1. 选择一个非空公式行。
2. 选择目标分区。
3. 点击 **保存到「分区名」**。

当前只保存**当前选中的公式行**。

## 7.3 分区

- **分区**：新建分区。
- **重命名**：修改分区名称。
- **删除分区**：删除分区及其中全部磁贴。
- 最多 12 个分区。
- 最多 30 个自定义磁贴。

没有分区时，必须先新建分区才能保存磁贴。

## 7.4 自定义磁贴右键菜单

- **设置 / 修改快捷键**
- **清除快捷键**
- **磁贴颜色**：自动色、预设色或任意颜色。
- **所属分区**：移动到其他分区。
- **删除磁贴**

删除磁贴只删除快捷入口，不修改已插入文档的普通 LaTeX。

# 8. 操作逻辑

入口：编辑区顶部 **操作逻辑**。

## 8.1 常用数学快捷转义

开启后，将普通输入自动映射为数学命令，例如：

```text
alpha → α
>= → ≥
hat → 重音结构
```

点击 **查看映射** 可查看当前完整映射表并搜索输入或 LaTeX。

微分元、函数名等正体自动检测独立运行，不受此开关控制。

默认：**关闭**。

## 8.2 光标自动跳出

- **上标输入后跳出**：输入一个字符或工具栏符号后返回主公式区域。
- **下标输入后跳出**：同上。
- **重音内容输入后跳出**：适用于 `hat`、`bar`、`vec`、`tilde`、`dot` 等。
- **字体命令输入后跳出**：控制 `\mathbb{}`、`\mathbf{}`、`\mathcal{}` 等作用域。

关闭“字体命令输入后跳出”后，可连续输入多个字符，再按 **Enter** 确认字体作用域。

以上四项默认：**开启**。

## 8.3 命令候选框

- **求和、积分等结构候选框**：控制 VisualTeX 大型结构候选；默认开启。
- **其他命令候选框**：控制其他 VisualTeX 大型候选；默认关闭。

这些开关不等同于 MathLive 自带的原生命令提示。

# 9. LaTeX 代码格式

代码格式决定：

- 源码区域显示方式
- 复制 LaTeX 时的包装格式
- 小键盘模式 `⌘S` 的复制格式

不会改变公式的数学内容。

## 9.1 单公式格式

| 格式 | 输出 |
|---|---|
| 纯 LaTeX 源码 | `\frac{x}{y}` |
| 行内公式 · 美元符号 | `$ ... $` |
| 行内公式 · 文字在公式外 | 顶层文字在公式环境外，公式片段使用 `$$...$$` |
| 行内公式 · 圆括号 | `\( ... \)` |
| 行间公式 · 双美元符号 | `$$ ... $$` |
| 行间公式 · 方括号 | `\[ ... \]` |
| `equation` | 每个公式一个自动编号环境 |
| `equation*` | 每个公式一个不编号环境 |

## 9.2 多行格式

| 格式 | 规则 |
|---|---|
| `align` | 多行合并；每行编号；支持 `&` 自主对齐 |
| `align*` | 多行合并；不编号；支持 `&` 自主对齐 |
| `aligned` | 放入 `\[...\]` 内；支持 `&` 对齐 |
| `gather` | 多行居中；每行编号 |
| `gather*` | 多行居中；不编号 |
| `multline` | 多行视为一个长公式；单一编号 |
| `multline*` | 多行长公式；不编号 |
| `equation + split` | 多行放入 `split`；外层一个编号 |
| `equation* + split` | 多行放入 `split`；不编号 |

默认代码格式：**行间公式 · 双美元符号**。

# 10. LaTeX 源码区

可视化编辑与源码编辑同步。

适合：

- 检查复杂 LaTeX
- 修改环境结构
- 检查 `align` 的 `&`
- 粘贴已有 LaTeX

## 10.1 标准布局

- **展开 LaTeX 源码**：打开下方源码区。
- **收起**：关闭源码区。
- **复制源码**：按当前 LaTeX 代码格式复制。

## 10.2 经典布局

底部面板可在：

- **公式工具**
- **LaTeX 源码**

之间切换。

底部面板支持：

- 拖动调整高度
- 双击分隔条恢复默认高度
- 收起 / 展开
- 源码页直接复制 LaTeX

源码暂时未闭合时，VisualTeX 会保留正在输入的源码；补全后再恢复完整可视化结构。

# 11. OCR

## 11.1 完整图片公式识别

入口：**主菜单 / 顶部按钮 → 图片公式识别**。

支持：

- 拖入图片
- 选择图片
- `⌘V` 粘贴剪贴板图片
- 更换图片
- 选择模型
- 开始 / 取消识别
- 编辑识别后的 LaTeX
- 复制 LaTeX
- 追加为新行
- 插入当前光标

建议只截取一条公式并尽量裁紧。

## 11.2 OCR 运行环境

首次使用时点击 **安装 OCR 运行环境**。

VisualTeX 使用本机 OCR 运行环境；默认 M 模型随运行环境准备。

运行环境已安装后可：

- **重启进程**：重启 OCR 工作进程。
- **重置环境**：删除并重新准备 OCR 运行环境。

## 11.3 OCR 模型

模型下拉框会标记：

- 已安装
- 未安装

未安装模型需导入对应 `.vtxocrmodel` 模型包。

- **导入模型包**：校验并安装模型。
- **删除模型**：删除可移除模型。
- 也可把 `.vtxocrmodel` 直接拖入模型区域。

L 模型占用空间和内存明显更高，无明确需求时优先使用 M。

## 11.4 公式框粘贴图片

1. 将光标放到目标公式位置。
2. 粘贴公式图片。
3. VisualTeX 自动识别。
4. 识别结果插回原光标位置。

顶部 **OCR 模型** 下拉框控制此功能使用的模型。

## 11.5 快捷 OCR

入口：编辑区顶部 **快捷 OCR**。

两种模式：

- **立即框选**：点击后最小化 VisualTeX，立即进入 macOS 框选截图。
- **等待系统截图**：先最小化并切换到目标页面，再使用 `⌘⇧3 / 4 / 5`。

识别过程会在主应用显示状态。

## 11.6 静默 OCR

开启编辑区顶部 **静默**。

快捷键：`⌘⇧O`

流程：

**任意应用中按快捷键 → 框选截图 → 后台识别 → LaTeX 自动复制到剪贴板**。

无需先打开 OCR 窗口。

# 12. 小键盘模式

点击 **小键盘**进入精简输入模式。

保留：

- 可视化公式编辑区
- 公式对齐与选中内容格式
- LaTeX 代码格式
- 小键盘退出按钮

隐藏普通主界面中不必要的文件、历史、设置等区域。

## 12.1 `⌘S` 行为

- 普通模式：`⌘S` 保存 VisualTeX 文档。
- 小键盘模式：`⌘S` 按当前 **LaTeX 代码格式**复制源码。

# 15. 自定义字符设计器

入口：**磁贴 → 自定义 → 字符设计器**。

用于组合 VisualTeX 内没有的数学字符，并注册为可直接输入的 LaTeX 命令。自定义字符库不再设置固定数量上限；实际可保存数量取决于本机可用存储空间和单个字符的矢量复杂度。

## 15.1 基本流程

1. 从裸字符素材库、扩展字体字符或几何图形中加入素材。
2. 在画布中点击图层，直接拖动、缩放或旋转。
3. 使用数学基线与参考字符检查比例。
4. 设置字符名称、命令、数学类型与可选的 Word OMML fallback。
5. 注册为 LaTeX 命令；最终尺寸由可见墨迹自动计算。

命令名只能使用英文字母。例如：

```latex
\selfdefa
```

注册后，该命令会进入公式输入候选，并保留在“自定义”区域中，不会自动加入“常用”磁贴；公式复制、粘贴、历史记录和重新编辑均保留原始命令。将公式移动到另一台设备时，还需要一并迁移自定义字符配置，否则该设备只能看到未解析的命令源码。

## 15.2 裸字符素材库

字符设计器不照搬主公式工具栏。素材区只保留可以独立作为一个字形使用的裸字符或裸符号：

- 按常用、微积分、希腊字母、关系、集合与逻辑、箭头、物理常用分类浏览；
- 分式、根式、矩阵、上下标、字体包装和其他需要参数的复合模板不会出现；
- 搜索会跨越全部裸字符分类，但仍不会把复合公式结构带入结果；
- 积分、求和等大型算子自动使用适合字形设计的显示样式；
- 已注册的自定义字符也可以作为裸字符再次组合；
- 手工输入框只接受单个 Unicode 字符或 VisualTeX 已识别的单个符号命令。

## 15.3 扩展字体字符

扩展字符区可浏览普通字母、数学字母扩展、希腊字母、运算符、关系符号、箭头、字母式符号和几何技术符号，并可按字符或 Unicode 编码搜索。

可选来源包括 Cambria Math、STIX Two Math、Latin Modern Math、XITS Math 和系统衬线回退字体。打包后的 macOS 应用通过 CoreText 读取本机字体，并把选中字形转换为自包含矢量轮廓；若首选字体缺失或不包含该字符，界面会明确显示实际回退字体。浏览器调试模式无法调用 CoreText，因此只使用带提示的实时字体预览。

- **数学斜体**：普通字母按数学斜体加入。
- **正体**：保持直立字形。
- Unicode 本身已经编码为数学斜体的字符不会再次叠加倾斜。

## 15.4 图层与 PowerPoint 式直接变换

每个 LaTeX 字形、系统字形或几何图形都是独立图层。点击图层后，画布直接显示八个缩放手柄和一个旋转手柄：

- 拖动四个角点默认等比缩放；按住 `Shift` 时可分别改变横向和纵向比例；
- 拖动四条边的中点只改变对应方向；
- 缩放时对角锚点保持在原位，字符不会边缩放边漂移；
- 拖动上方旋转手柄可连续旋转；按住 `Shift` 时按 15° 吸附；
- 仍可在右侧精确设置 X、Y、横纵缩放、倾斜和角度；
- 支持水平翻转、垂直翻转、复制、删除、显示、隐藏、锁定和图层顺序；
- 对字形可进行非破坏裁剪，或拆分为上/中/下、左/中/右三个可编辑部分。

翻转和旋转围绕图层自身视觉中心进行，不会把字符绕画布原点甩到其他位置。

## 15.5 空心、擦除与透视

- **智能矢量空心**：把所选图层转换为统一粗细的矢量描边，并按图层缩放补偿线宽，避免同一字符放大后描边随之失控。
- **橡皮擦**：生成真正的透明矢量擦除路径，不依赖白色或当前背景色遮盖。
- **三维挤出透视**：设置深度、方向和挤出层数，生成可与空心效果叠加的矢量透视。

空心和实心图层可以同时存在；效果只作用于当前图层，不会把其他图层一并改成空心。

## 15.6 数学基线与参考

- 淡色虚线表示数学基线；
- 参考字符与当前字符共用基线，用于比较高度、宽度和视觉中心；
- 可切换普通字母、积分、闭合积分、求和、连乘和集合大运算符等参考类型；
- 参考字符只用于对照，不会进入最终墨迹尺寸。

## 15.7 无边界画布与自动墨迹边界

中间工作区采用视觉上的无边界画布，不再显示固定纸张或输出框：

- 可在空白处拖动画布，并通过滚轮或右上角按钮缩放；
- **定位**会让当前可见墨迹重新进入视野；
- 背景使用低对比度、轻微虚化的点阵，只辅助定位，不参与导出；
- 右上角实时显示当前可见墨迹的宽高；
- 字符宽度和高度根据实际可见墨迹、描边、旋转、裁剪和透视自动计算，不需要手工维护画布宽高；
- 数学基线仍决定字符在公式中的上升部和下降部位置；
- 非破坏裁剪只改变可见墨迹，不删除原始字形数据；
- 注册时会再次生成紧凑运行时边界，避免工作区空白进入公式行高或导出图片。

## 15.8 已注册字符

已注册字符区域可再次编辑、复制为新草稿或删除。保存更新时会保留可编辑素材、图层、裁剪、变换和效果参数。字符库使用分记录索引保存，并保留上一份完整索引；当前一代记录不完整时会回退到上一份完整字符库，而不是只加载剩余部分。

删除已注册字符后，已有公式中的该自定义命令仍保留源码，但会变为未解析状态。需要恢复显示时，可重新注册同名命令或从配置备份中恢复字符库。

# 21. 容易混淆的功能

## 常用工具 vs 常用磁贴 vs 自定义磁贴

- **常用工具**：已有公式结构或命令的高频入口。
- **常用磁贴**：VisualTeX 内置的完整公式。
- **自定义磁贴**：用户保存的完整公式行。

## 整行对齐 vs `align` 对齐

- **左 / 中 / 右对齐**：控制整行公式在编辑区的位置。
- **`align` 的 `&`**：控制多行公式内部共同对齐点。

## 保存 vs 复制 LaTeX vs 导出

- **保存**：生成可继续编辑的 VisualTeX 文档。
- **复制 LaTeX**：按当前代码格式复制源码到剪贴板。
- **导出**：生成 Markdown、SVG、PNG 外部文件。

## 图片公式 vs OMML

- **图片公式**：VisualTeX 渲染结果，适合保持统一视觉样式。
- **OMML**：Word 原生公式，可直接使用 Word 原生公式工具编辑。
