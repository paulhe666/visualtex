# Fonts in this folder

The `vtx-*.otf` fonts are OpenType (CFF) conversions of the Type 1 fonts that
LaTeX uses for mathematics:

- Computer Modern and AMS symbol fonts (cmr, cmmi, cmsy, cmex, cmbx, cmti, cmss,
  cmtt, cmmib, cmbsy, msam, msbm, eufm), from the AMS Type 1 versions in TeX Live.
  Copyright (c) 1997, 2009 American Mathematical Society. SIL Open Font License 1.1.
  The original names (cmr10, ...) are Reserved Font Names; a format conversion is a
  Modified Version, so these fonts are renamed ("VTX Roman 10", ...).
- RSFS script fonts (rsfs5/7/10), Type 1 by Taco Hoekwater. CTAN license: "other-free".
  To confirm before distribution.

Each TeX character code c is mapped to U+E000+c (Private Use Area).
